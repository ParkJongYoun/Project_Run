# 누끼이쁘게따줘

로비에 겹쳐 놓을 캐릭터·사물의 **배경 제거와 윤곽선 마무리**를 함께 수행한다. 목표는 거친 끝을 잘라내는 데서 끝내지 않고 원래 그림의 선이 자연스럽게 이어지는 투명 PNG·스프라이트를 만드는 것이다.

현재 프로젝트에 `ProjectSupport/Skills/pretty-cutout`이 있으면 그 동봉본을 우선한다. 프로젝트 저장·도구·Unity 규칙은 현재 체크아웃의 지침을 따르고, 다른 프로젝트의 화면 구성이나 게임 사양을 가져오지 않는다.

## 입력과 범위

- 현재 대화에서 지정한 이미지·기존 영상·추출 프레임·시트를 확인한다. 어떤 자료인지 이미 알 수 있으면 정지 이미지인지 전체 프레임인지 다시 묻지 않는다. “그 영상에서 뽑은 스프라이트도”는 기존 애니메이션 전체 프레임의 경계 정리다.
- 가능하면 **알파 처리 전의 RGB 원본 프레임**에서 다시 시작한다. 이전 누끼에서 잃은 검은 선이 원본에 남아 있을 수 있다. MP4가 없어도 원본 RGB PNG와 PTS 기록이 있으면 재생성 없이 처리한다.
- 동봉 스크립트는 균일한 **마젠타 배경의 불투명 RGB/RGBA**용이다. 이미 투명한 PNG를 RGB로 바꾸어 다시 키잉하거나 일반 실내 배경에 이 키어를 적용하지 않는다. 알파본만 남았으면 원본을 찾고, 없으면 기존 알파를 보존하는 별도 경계 편집으로 분기한다. 새 그림을 그려야 하는 결손 복원에는 환경에서 허용하는 이미지 편집 도구를 사용하며 실제 복원 범위를 구분한다.
- 원래 선이 있는 애니메이션은 일관된 결정적 후처리를 우선한다. 프레임별 전체 재작화로 얼굴·옷·윤곽이 바뀌거나 떨리는 결과를 만들지 않는다.
- 해상도·길이·FPS·프레임 수·순서·기존 동작·공통 피벗을 유지한다. 800셀·512px 등의 다른 제작 규격을 이 경계 수정에 자동 적용하지 않는다. 영상 재생성, 프레임 감축, 배경 환경 효과 변경은 이 요청으로 추가하지 않는다.

## 처리와 판단

처리 전에 [실행·조정 방법](references/workflow.md)을 읽는다. 이번에 좋게 보였던 실제 조건과 검증 범위는 [와일드로즈 사례](references/wildrose-case.md)에 있다.

1. 원본과 기존 누끼를 같은 크기로 보고, **검은 원래 선 / 실제 조명 하이라이트 / 키색 오염 / 잘린 그림**을 구별한다. 밝은 가장자리를 모두 오류로 지우지 않는다.
2. 키색을 제거할 때 침식한 안쪽의 밝은 옷·피부색을 윤곽 전체에 퍼뜨리지 않는다. 오염되지 않은 원래 선 가까이에서 색을 추정하고, 알파와 RGB를 따로 복원한다.
3. 실루엣의 계단·압축 부스러기를 작은 폭에서 매끈하게 만든다. RGB 역합성은 평활화하기 전의 커버리지를 사용한다. 평활 알파로 색까지 계산하면 녹색 테두리가 생길 수 있다.
4. 필요한 경우 실루엣의 좁은 띠 안에서 원래 선과 어울리는 색으로 끊긴 경계를 연결한다. 와일드로즈의 약 1~2 원본 픽셀 폭은 사례값이다. 새 대상의 선 굵기·크기·화풍에 맞추며 굵은 검정 외곽선이나 흐린 띠로 문제를 가리지 않는다. 자연스러운 털·머리카락·흰 프릴을 함께 본다.
5. 마젠타와 비슷한 리본·장비는 실제 색과 움직이는 형태를 따라 보호한다. 사례의 고정 검색 사각형은 보호를 탐색할 범위일 뿐 전체를 불투명하게 만드는 마스크가 아니다. 얇거나 떨어진 정상 부품을 작은 성분이라는 이유만으로 제거하지 않는다.
6. 같은 설정과 좌표계로 전체 프레임을 처리한다. 프레임별 자동 크롭·확대·중앙 정렬을 하지 않는다. 움직이는 프레임을 좌표 정렬 없이 시간 평균하여 잔상을 만들지 않는다. 시트가 필요하면 전체 프레임이 들어가는 **공통 크롭·셀·피벗**으로 기존 조립기를 사용한다.

## 검수와 결과

- 대표 자세뿐 아니라 전체 프레임의 잘림·빈 셀·보호색·내부 구멍을 검사한다. 밝은 배경, 어두운 배경, 실제 로비 배경에서 원래 크기와 확대 상태를 확인한다.
- 정상 속도·느린 속도·마지막→첫 프레임을 확인한다. 소매·머리끝·꼬리·손 사이 틈·가는 선의 깜빡임을 본다. 알파 변화량에는 정상 동작도 포함되므로 수치만으로 떨림이 해결됐다고 판정하지 않는다. 원본 동작의 루프 불연속과 알파 경계 문제는 구분한다.
- 원본 해시와 PTS를 보존하고, 설정·도구 버전·대표 프레임 재현 결과·수정 띠 밖 검증 범위·셀 크기·공통 배치·실제 시각 검수 결과를 기록한다. RGB 내부 보존 검사는 스크립트가 판별한 안전한 불투명 내부에 대한 검사이며, 전체 의미적 캐릭터 영역 보존을 보장하지 않는다.
- 새 버전으로 저장한다. 원본 영상·프레임·기존 시트를 삭제하지 않는다. 결과는 현재 프로젝트의 제작 원본 위치에, 공용 처리 코드는 스킬 또는 프로젝트 공용 도구 위치에 둔다.
- Unity 적용이 요청되었거나 현재 대화에서 이미 승인되어 있으면 기존 대상 참조만 교체하고 실제 재생·알파·일시정지·누락 참조를 검사한다. 현재 PPU·배율·UI 계층을 유지하며 불필요한 런타임 코드 변경을 피한다. 설치만 요청했다면 게임 에셋을 변경하지 않는다.
- 검수용 합성 영상이 **고정 배경**이면 그렇게 표시한다. Unity의 커튼·배경 변형 효과와 다른 조건의 미리보기로 환경 움직임까지 개선됐다고 설명하지 않는다.

완료 시 결과 경로, 실제 프레임 수·시간, 경계 수정 범위, Unity 적용 여부와 남은 압축·동작 한계를 짧게 알린다. 정지 PNG의 AI 재작화와 기존 애니메이션의 원본 선 복원은 서로 다른 작업임을 구분한다.
