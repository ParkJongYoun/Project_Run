# 와일드로즈에서 검증한 사례

2026-10-17 Project Run 로비에서 사람 둘과 고양이가 한 묶음인 기존 애니메이션에 적용했다. 사용자는 결과를 보고 기존 최초 적용본보다 괜찮아 보인다고 평가한 뒤 **“누끼이쁘게따줘”라는 재사용 스킬과 SGL 복사**를 요청했다. 새 대상 전체에 대한 품질 보장이나 최종 배포 규격 승인은 아니다.

## 기존 결과와의 차이

- 이전 알파 처리에서는 안쪽 색을 윤곽으로 전파하면서 원본의 검은 선 일부가 밝은 테두리로 바뀌었고 머리·소매·꼬리에 거친 경계가 남았다.
- 원본 RGB 프레임을 다시 사용해 선 가까이의 색을 기준으로 알파·RGB를 복원했다. 원래 커버리지와 평활 알파를 분리하고 약 1~2픽셀의 좁은 잉크 띠로 끊긴 경계를 연결했다.
- 원본 영상 재생성이나 프레임별 AI 재작화는 수행하지 않았다. 앞서 ImageGen으로 정리한 정지 PNG와는 다른 처리다. 정지 PNG의 새 얼굴·옷 디테일을 애니메이션에 이식한 결과가 아니다.
- 사용자에게 보여준 9.125초 확인 영상은 **배경 고정 + 캐릭터 3회 반복 합성본**이다. Unity의 기존 커튼·배경 변형 효과는 그대로 남았다. 비교가 안정적으로 보인 이유를 모두 알파 개선 덕분이라고 단정하지 않는다.

## 실제 수치와 위치

| 항목 | 값 |
|---|---|
| 원본 프레임 | 1024×768 RGB, 73장, 24fps |
| 실제 시간 | 3.0416666666666665초, 원본 PTS 유지 |
| 공통 패킹 셀 | 898×646, 원본 배율 유지 |
| 공통 크롭 | 좌상단 기준 `[75,66,973,712]` |
| 원본 배경 | 1672×941 |
| 영상 원점·환산 | `[288,-80]`, 영상 1픽셀 = 배경 원본 1.375픽셀 |
| 보호 분홍 검색 범위 | `[350,390,715,710]` — 와일드로즈 원본 프레임 전용 |
| 공간 평활 | sigma `0.7`, coverage range `[0.12,0.88]` |
| 경계 잉크 | band `[1.65,1.15]`, gain `0.32`, RGB min `[24,18,14]`, max `[65,48,38]` |
| Unity 확인 | Canvas 기준1280×720, Game View1920×1080, RGBA32, 무압축·밉맵 없음·임포트 축소 없음 |

다른 키 수치는 [설정 예제](settings.example.json)의 `matte`와 같다. 예제에서는 다른 대상에 사각형을 잘못 복사하지 않도록 `warmPinkSearchRects`를 비워 두었다. 이번 사례를 정확히 재현할 때만 위 분홍 범위를 넣는다.

이 경로는 출처 기록이며 SGL에서 실행할 필수 입력이 아니다. SGL에는 이 스킬의 문서·도구만 복사하고 Run의 캐릭터·로비 에셋이나 화면 사양은 이식하지 않는다.

## 실제 검증과 남은 한계

원본73장 해시와 안전한 불투명 내부 픽셀, 대표0·36·62·72번 프레임의 재현 일치, 패킹 픽셀 일치, 기존 아틀라스 보존을 확인했다. Unity에서73장 모두 관찰했고 반복3회, UI 일시정지·재개, 누락 참조0, Console 오류·경고0을 확인했다. 작업 후 Play를 종료했다.

원본 영상의 작은 해상도·압축 흔적, 원래 자세·텍스처 흔들림과 루프 접합 특성은 남는다. 경계 정리가 영상 자체의 불연속이나 배경 변형을 해결하지 않는다. 해당 작업에서는 WebGL·모바일 성능을 새로 측정하지 않았다.
