# Project Run 카툰 외형

이 파일은 개인 스킬 목록에서 프로젝트 정본으로 연결하는 진입점이다. 실제 작업 절차와 수치를 여기에 복제하지 않는다.

1. 현재 작업이 Project Run인지 확인한다. 기본 저장소 위치는 `D:/Project_Run`, Unity 루트는 `D:/Project_Run/Run`이다.
2. `D:/Project_Run/ProjectSupport/Skills/project-run-cartoon-look/SKILL.md`를 읽고 해당 절차를 적용한다. 사용자가 명시한 다른 Project Run 체크아웃에서 작업 중이면 그 체크아웃의 같은 상대 경로를 사용한다.
3. 저장소의 `AGENTS.md`와 `Run/DataBundles/기획/Project_Run_개발_규칙.md`, 정본에서 연결한 참조 문서를 읽는다. 최신 사용자 지시가 기본 스타일과 적용 범위보다 우선한다.
4. 경로가 사라졌으면 현재 Project Run 체크아웃에서 정본을 먼저 찾는다. 없으면 기록된 절차를 읽을 수 없다고 알리고 필요한 프로젝트 위치를 확인한다. 과거 대화나 추측으로 수치·에셋을 만들어내지 않는다.

정본과 연결한 두 참조 문서만 유지보수하면 된다. 프로젝트 `AGENTS.md`에도 호출 문구가 있어 개인 스킬 목록이 갱신되기 전에도 프로젝트 작업에서 이 절차를 찾을 수 있다.
