# 신규 미노 카툰 품질 저하와 복구

2026-10-20 사용자 피드백: 신규 미노의 카툰형이 원본보다 품질이 낮아 재수정했다. 이 문서는 확인된 실패와 복구 방법이다. 수정본의 Editor 검증은 완료했으며 사용자 외형 승인을 뜻하지 않는다. 다른 캐릭터의 수치로 그대로 복사하지 않는다.

## 확인된 원인

| 항목 | 최초 카툰의 문제 | 재수정 |
|---|---|---|
| 알베도 | 원본 파일 4096²를 생성 이미지 1254²로 바꿨고 Unity에서는 NPOT 축소로 1024²가 됨 | 원본 바이트 그대로 전용 복사, 파일/실제 임포트 모두 4096² |
| UV와 색 | 잘게 나뉜 UV 섬의 채색이 달라져 피부에 조각 얼룩이 생기고 얼굴·가죽 장식 디테일이 소실됨 | 재생성 결과 참조를 해제하고 기존 UV·색 위치를 보존 |
| 입체감 | 원본의 2048² 노멀맵이 새 표면 셰이더에서 빠졌고 좁은 명암 경계가 불균일함을 강조함 | 노멀맵 전용 복사 + 대상 전용 셰이더의 tangent/normal 변환, 강도 .7과 부드러운 경계 |
| 검수 | 캡처·메시 동일성 검사를 했다는 이유로 눈에 보이는 품질 저하를 통과시킴 | 원본과 동일 포즈·카메라·조명 비교 후 얼굴/옆/뒤/동작 확인 |
| 전시 동작 | 수동 graph.Evaluate 직후 뼈는 움직였지만 기본 Idle Controller가 실제 렌더 프레임의 포즈를 다시 덮어씀 | Sys_CartoonShowcase가 전시 인스턴스의 controller를 분리해 동작 전담 |

원본 알베도의 기존 Unity 임포트는 2048²였다. 원본 파일 4096², 원본 임포트 2048², 거절 시안 임포트 1024²를 혼동하지 않는다. 현재 수정본의 알베도는 실제 4096²이며 노멀맵은 파일 자체가 2048²다.

메시 UV/버텍스/삼각형은 원본과 동일했다. 초기 조사에서 겹친 위치의 버텍스 노멀도 동일했으므로, 이 사례의 조각 얼룩을 노멀 스무딩만으로 해결할 문제로 판단하지 않았다. 다른 대상의 경계 문제에는 따로 확인한다.

## 다음 유사 작업에서의 판단

1. 모델에서 먼저 원본 품질 기준을 확보하고 알베도·노멀맵·메시 노멀·조명을 구분해 확인한다.
2. 원본 파일, 편집 파일, 실제 임포트 크기를 각각 기록한다. 4K 요청 문구나 임포터의 최대 크기만으로 4K 결과라고 보고하지 않는다.
3. 미세 UV atlas의 생성 편집 결과가 형태/얼굴을 손상시키면 원본 전용 복사본으로 돌아가 카툰 셰이더를 조절한다. 동일 이미지를 확대하거나 경계만 더 세게 하는 것으로 손실을 감추지 않는다.
4. 원본 노멀맵이 외형을 만드는 경우 복사·연결하고 tangent 유무와 정상 변환을 확인한다. 공용 셰이더를 바꾸는 대신 대상 전용 버전을 사용한다.
5. 원본과 같은 포즈·조명에서 얼굴·흉부·뿔·장식, 정면·측면·후면·실제 표시 크기를 비교한다. 얼룩·흐림·무늬 단절이 남으면 완료로 표시하지 않는다.
6. 동작 이름·뼈 변화 수치뿐 아니라 실제 재생 프레임을 확인한다. Controller/Playable 이중 제어는 전시가 소유한 인스턴스에서만 정리한다.
