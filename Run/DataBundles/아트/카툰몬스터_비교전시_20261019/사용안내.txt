- 신규 카툰 6종: 일반 포링, 페코페코, 데비루치, 바포메트, 바포메트 주니어, 탈것 여우

- 여우는 fox_001 탈것 원본이며 구미호 몬스터로 확정하지 않았습니다. 실제 모델은 꼬리 하나입니다.
- 사막늑대는 사용자의 제외 지시를 따라 추가하지 않았습니다.

Play Mode 조작
- 전체 보기: 14종을 두 줄로 표시
- 이전/다음 몬스터: 한 마리 확대, 다른 몬스터와 이름표 숨김
- 45도 회전: 확대 중인 몬스터 회전
- 대기/달리기: 원본에서 복제한 애니메이션 재생
- 테스트 목록: 테스트 타이틀 복귀
전시용 크기 보정은 씬의 V_Cartoon_* 아래에만 적용했습니다.

신규 독립 리소스
- 프리팹: Assets/Resources/Prefabs/Race/CartoonMonsters/P_Runner_Cartoon_{ID}.prefab
- 텍스처/메시/아바타/클립/재질: Assets/ArtBundles/Characters/CartoonMonsters/{ID}
- 기존 UV atlas를 입력으로 built-in image_gen에서 6장 각각 새 카툰 알베도를 생성했습니다.
- 최종 파일은 1254x1254 PNG, Unity 임포트는 1024x1024, sRGB/밉맵/비압축입니다.
- 기존 승인 카툰 셰이더와 윤곽선을 사용합니다.

검증

- 기존 원본/카툰 리소스 5604개 해시 일치
- Editor PC 품질에서 대기/달리기, 확대/회전/전체 보기, 테스트 타이틀 왕복 확인
- 신규 6종 정면/측면/후면 18장 검수
- 기존 경기 씬의 출전 구성은 변경하지 않았습니다.
- WebGL 빌드/브라우저 검증은 이번 작업에 포함하지 않았습니다.
- 콘솔에는 기존 Unity AI NoSubscription 로그가 있으며, 작업 코드의 컴파일/실행 오류는 관찰되지 않았습니다.
