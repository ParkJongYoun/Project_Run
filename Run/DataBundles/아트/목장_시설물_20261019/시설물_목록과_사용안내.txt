조작
1. Scene_LobbyTest를 열고 Play한다.
2. 하단 건설 → 시설 카드 선택 → 바닥을 누르거나 끌어 위치 지정 → 배치.
3. 초록 영역은 배치 가능, 빨간 영역은 겹침 또는 잠긴 영역이다.
4. 건설 모드에서 기존 시설을 누르면 이동할 수 있다. 취소는 이전 위치로 복원한다.
5. R: 회전 / Enter: 배치 / Esc: 선택 취소. 기존 시설을 고른 뒤 회수하면 제거된다.
6. 우클릭·가운데 버튼 드래그: 카메라 이동 / 휠: 확대·축소. 터치는 두 손가락 이동·확대·축소 코드가 연결되어 있다.
7. 목장 메뉴는 기본 시점으로 돌아간다. 설정의 '기본 배치로'는 확인 후 목장 배치를 초기화한다.

저장과 기존 게임의 관계
- 자동 저장 키: ProjectRun.Ranch.LobbyTest.Layout.v1
- 에디터에서는 PlayerPrefs, WebGL에서는 해당 빌드의 브라우저 로컬 저장을 사용한다. 현재 기기 간 동기화는 없다.
- 배치 확정/회수/초기화 때 저장하고, 씬 시작 때 유효한 저장을 복원한다. 비정상/중복/범위 밖 저장은 기본 배치로 복원한다.
- 기존 DemoUser 선택·훈련·경기 기록을 변경하지 않는다.
- 상단 재화와 레벨은 시제품 표시값이다. 이번 배치는 무료이며 재화 구매/소모/시설 생산/성장/훈련 완료 시간 계산은 구현 범위에 포함하지 않았다.
- 몬스터 메뉴는 기존 데모 데이터의 정보를 표시한다. 경기장 메뉴는 기존 정식 출전 흐름을 안내하며 이 씬에서 경기 씬으로 이동하지 않는다.
- 기존 Scene_Lobby와 정식 타이틀/로비/경기 씬, 웹 빌드 메뉴/설정은 수정하지 않았다. 이 씬을 웹 빌드에 새로 포함하거나 빌드하지 않았다.
