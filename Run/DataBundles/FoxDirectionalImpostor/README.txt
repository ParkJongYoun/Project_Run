여우 한 자세 / 다방향 깊이 임포스터 실험

실행
- Assets/Scenes/Scene_FoxImpostorTest.unity를 열고 Play.
- Unity 메뉴 Project Run > Fox Impostor > Open orbit test로도 열 수 있다.
- 화면 드래그: 좌우 / 위아래 회전. 휠 또는 거리 슬라이더: 확대·축소.
- 좌우 / 위아래 슬라이더로 정확한 각도를 지정한다.
- 자동 회전: 좌우를 돌면서 높이를 -75~75도로 바꾼다. 드래그나 각도 슬라이더를 조작하면 멈춘다.
- 원본 3D 보기 / 2D 임포스터 보기 버튼 또는 Space: 같은 카메라에서 비교.
- 상단 144 / 72 / 40 / 24 / 16 / 12장 버튼: 카메라 각도·거리와 고정 자세를 유지하면서 시점 수만 바꾼다. 현재 기본값은 16장(아래쪽 촬영 줄 제거).
- 시점 초기화 버튼 또는 R: 기본 시점. 아래쪽까지 직접 볼 수 있다(-89.9~89.9도).

구성
- 현재 Scene_All3D의 P_Runner_03 여우 모델을 복제해 RunClip의 보행 위상 0.18에서 고정했다.
- 탈것 여우만 사용한다. 얼굴, 귀, 꼬리, 장신구, 무늬와 자세는 모든 시점에서 동일한 메쉬를 기준으로 한다.
- 현재 여우의 툰 재질을 독립된 참조 재질·셰이더로 복사했다. 이 테스트의 원본 비교와 캡처가 같은 재질을 사용한다.
- 이번 자산은 동일한 3D 원본에서 방향별로 렌더링한 이미지다. 구도별 AI 재드로잉은 수행하지 않았다.
- 좌우 16방향 x 높이 9단계(-90~90도), 144개 시점. 극점도 방향별 카메라 롤에 맞춰 촬영했다.
- 색상 타일 384x384, 2배 해상도로 촬영 후 축소. 깊이는 16비트를 RG 채널로 저장한다.
- 색상/깊이 아틀라스 각각 6144x3456. 색상 sRGB, 깊이 Linear, 압축·밉맵 없음.
- 실제 표시 객체는 정점 4개 / 삼각형 2개의 평면 하나다. 원본 여우 메쉬는 비교 버튼을 켤 때만 활성화한다.
- 카메라 방향에 가까운 네 시점을 골라 깊이를 따라 픽셀 위치를 재투영하고, 겹치는 표면만 섞는다.
- 보정한 표면의 깊이를 기록하므로 바닥 격자와의 앞뒤 관계도 이미지의 입체 위치를 따른다.
- 기본 거리에서 720x1280과 720x1600의 화면비를 고려해 여우 전체가 보이도록 맞췄다.

- Assets/ArtBundles/FoxDirectionalImpostor: 고정 참조 메쉬/프리팹, 재질, 셰이더, 아틀라스.
- Assets/Scripts/Test/FoxImpostor: 임포스터 표시와 테스트 조작/UI.
- Assets/Scripts/Editor/Racecourse/FoxDirectionalImpostorBuilder.cs: 포즈 추출, 씬 생성, 촬영 도구.
- Assets/Scripts/Editor/Racecourse/FoxDirectionalImpostorValidation.cs: 원본/임포스터 이미지 비교.
- DataBundles/FoxDirectionalImpostor/Views: 방향별 144개 색상 이미지.
- Review/*_3D_vs_2D.png: 왼쪽 원본 3D / 오른쪽 2D 임포스터. 같은 원근 카메라에서 비교.
- Review/comparison.csv: 10개 시점의 윤곽 IoU와 색상 차이.
- Review/orbit-test-final.png: 실제 Play Mode 조작 화면.

검증
- 비어 있는 촬영 이미지 0개 / 144개.
- 정면, 사선, 위, 아래, 위·아래 극점, 360도 연결 경계, 측면, 후면의 10개 비교.
- 512x512 비교에서 윤곽 IoU 0.9594~0.9818. 이는 정적 윤곽 비교이며 동영상 품질 점수가 아니다.
- 두 세로 화면비 x 좌우 8방향 x 높이 5단계 = 80개 조합에서 기본 거리의 원본 정점이 화면 밖으로 나간 경우 0.
- Input System 마우스 입력으로 비교 버튼 클릭 확인.
- 가상 마우스 드래그: (65도,15도)에서 (41도,0도)로 양축 회전 확인.
- UI 버튼·슬라이더의 2D/3D 전환, 좌우, 높이, 거리, 자동 회전, 초기화 연결 확인.
- 2D 모드에서 원본 객체 비활성 / 평면 활성, 3D 모드에서 반대로 전환됨.
- 테스트 씬 Play Mode와 임포스터 셰이더의 컴파일 오류 없음.

범위와 한계
- 한 자세의 시점 변화 실험이다. 달리기 프레임이나 경기 중 교체는 이번 작업에 넣지 않았다.
- 조명은 촬영 당시의 모습을 담는다. 동적인 조명 재계산용 노멀맵은 포함하지 않는다.
- 가까이 확대하면 꼬리 끝, 털의 가는 경계, 장식에서 픽셀 번짐이나 작은 틈이 보일 수 있다.
- 깊이 레이 탐색과 네 시점 결합은 픽셀 연산 비용이 크다. 원본보다 빠르다는 검증은 하지 않았다.
- 텍스처 두 장의 기본 비압축 GPU 저장량은 합계 약 162 MiB다. 참조 메쉬/기타 리소스는 별도다.
- PNG 파일 합계 약 13.1 MiB. 모바일 WebGL 빌드·성능·메모리 검증은 하지 않았다.
- 기존 Scene_All3D의 경기 흐름이나 빌드 씬 목록을 이 실험으로 변경하지 않는다.

시점 수 축소 비교 추가
- 좌우 x 높이 구성: 144=16x9, 72=8x9, 40=8x5, 24=8x3, 12=4x3.
- 모든 버전은 같은 384x384 타일, 색상·깊이, 같은 셰이더와 재투영 설정을 쓴다.
- 144장 원본의 해당 방향 타일만 골라 더 작은 아틀라스로 다시 묶었다. 남은 시점을 새로 그리거나 해상도를 낮추지 않았다.
- 작은 아틀라스는 Assets/ArtBundles/FoxDirectionalImpostor/Variants, 데이터는 Assets/Resources/FoxImpostor/Variants에 있다.
- 재생성 메뉴: Project Run > Fox Impostor > Build reduced view presets. 원본을 다시 촬영한 경우 이 메뉴로 축소 버전도 다시 만든다.
- Review/ReducedViews/comparison.csv와 *_3D_vs_2D.png에 각 버전당 동일한 10시점, 총 50개의 원본 3D 비교를 저장했다.
- 10시점 평균 윤곽 IoU: 144장 0.9750 / 72장 0.9716 / 40장 0.9647 / 24장 0.9523 / 12장 0.9442.
- 이 값은 정적 외곽선의 겹침이다. 내부 장식, 눈·얼굴의 왜곡, 움직이는 카메라의 연속성을 대표하는 점수가 아니다.
- 후면 사선에서 24장·12장의 장식/꼬리 주변 틈이 더 크다. 최초 축소 비교의 시작점은 40장이었다.
- 상단 다섯 버튼의 선택 자산·텍스처 변경, 카메라 고정, 원본 숨김을 확인했다. 기존 회전/거리/3D 비교 기능도 유지한다.
- 각 버전을 단독으로 쓸 때 두 아틀라스의 비압축 기본 GPU 저장량: 162 / 81 / 45 / 27 / 13.5 MiB.
- 최초 다섯 버전의 아틀라스 합계는 약 328.5 MiB다. 현재는 아래의 16장 버전까지 여섯 버전을 함께 참조한다. 버튼 선택만으로 전체 메모리가 선택한 버전의 수치로 줄어드는 테스트는 아니다.
- 네 시점 결합과 깊이 레이 탐색은 그대로라, 이미지 수 감소가 같은 비율의 FPS 개선을 뜻하지 않는다. 모바일 WebGL 성능 측정은 별도다.

배 쪽 줄을 제거한 16장 실험 (2026-10-16)
- Fox_24_Color.png 및 Fox_24_Depth.png의 맨 아래 -90도 줄을 제거했다. 위 +90도 줄과 가운데 0도 줄은 픽셀 그대로 유지했다(색상·깊이 모두 원본 대비 불일치 픽셀 0).
- 좌우 8방향 x 높이 2단계. 각 타일 384x384, 아틀라스 각각 3072x768.
- 자산: Assets/ArtBundles/FoxDirectionalImpostor/Variants/Fox_16_Color.png, Fox_16_Depth.png, Fox_16.mat.
- 데이터: Assets/Resources/FoxImpostor/Variants/FoxImpostor_16.asset. 촬영 높이 범위를 MinimumElevation=0, MaximumElevation=90으로 명시한다.
- 0도는 바닥 높이가 아니라 여우 중심을 수평으로 바라보는 시점이다. 중심보다 위에서 내려다보는 범위가 0~90도다.
- 카메라는 이전처럼 -89.9~89.9도로 움직인다. 16장 선택 중 0도 아래에서는 수평 줄만 사용하고 '촬영 범위 밖 · 아래쪽 이미지 없음'을 표시한다. 사라진 배 정보를 복원하지는 않는다.
- Review/Upper16/comparison.csv 및 18개의 원본 3D/임포스터 비교 이미지: 24장·16장 각각 위쪽 5시점과 아래쪽 4시점.
- 위쪽 다섯 시점에서 24장과 16장의 윤곽 IoU는 소수점 네 자리까지 같았다. 드문 래스터 경계 픽셀 차이는 있다.
- 좌우 65도에서 아래 -5/-10/-20/-30도일 때 16장 윤곽 IoU는 0.9631/0.9509/0.9171/0.8725, 24장은 0.9685/0.9645/0.9554/0.9557이었다. -30도에서는 배와 다리 사이의 결손이 뚜렷하다. 모든 좌우 방향에 공통인 허용 각도를 뜻하지 않는다.
- 재생성 메뉴: Project Run > Fox Impostor > Add 16-view upper hemisphere. 전체 축소 버전 재생성 메뉴도 마지막에 16장을 다시 만들고 기본 선택한다.
- Play Mode에서 여섯 버튼의 선택 변경·카메라 유지·원본 숨김, 16장 선택 시 범위 밖 경고와 범위 안 복귀를 확인했다. 콘솔 오류·경고 0. Review/Upper16/upper16-test-ui.png와 below-range-ui.png에 조작 화면을 저장했다.
- 16장 색상+깊이 아틀라스의 기본 비압축 GPU 저장량은 18 MiB. 여섯 버전을 모두 참조하는 비교 씬의 아틀라스 합계는 약 346.5 MiB.
- 이 16장도 기존 3D 캡처의 일부다. 모델 없이 새 캐릭터를 그려 넣는 실험은 아직 수행하지 않았다. 새 캐릭터로 교체하려면 해당 캐릭터의 시점별 색상·알파와 일치하는 깊이, 공통 중심·스케일이 필요하다. 여우 깊이맵을 그대로 쓰면 새 실루엣과 재투영 위치가 맞지 않는다.
