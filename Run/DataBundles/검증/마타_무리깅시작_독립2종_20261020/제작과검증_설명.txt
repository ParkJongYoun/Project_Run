마타 무리깅 시작 · 독립 달리기 2종 (2026-10-20)

최종 파일: 마타_무리깅부터새제작_2종달리기.blend
Space로 재생/정지. 30fps, 1~96프레임 반복.
왼쪽 파랑: 1번, 기존 마타 동작 참고. 24프레임 주기.
오른쪽 초록: 2번, 독립 제작한 강아지 러닝 트로트. 32프레임 주기.
96프레임은 두 주기의 공배수이며, 97프레임은 1프레임과 같은 검증용 끝점.

시작 조건
- 제공된 FBX를 새로 불러온 즉시 메시의 기본 정점과 재질/텍스처만 복사.
- Armature 객체/모디파이어, 부모 연결, 웨이트 그룹, 액션을 모두 제외.
- 트리포 뼈의 이름/좌표/계층/웨이트를 읽거나 관절 가이드로 사용하지 않음.
- 메시만 들어 있는 작업기록/마타_뼈와웨이트없는_시작.blend를 저장한 후 실제 다시 열었음.
- 이 시점의 Blender 데이터: Armature 0, 액션 0, 메시 웨이트 그룹 0, 모디파이어 0.
- 이전 비교 작업의 뼈대 및 애니메이션 데이터는 새 시작 파일에 포함되지 않음.

새 리깅
- 메시 옆면/앞면 실루엣과 정점 높이별 단면을 관찰하여 관절 위치를 새로 설계.
- 새 해부학적 뼈 24개: 몸통/목/머리, 앞다리, 무릎/발목을 나눈 뒷다리, 곡선 꼬리.
- 이 새 설계와 새로 계산한 웨이트를 두 버전에서 공유함. 트리포 리깅을 공유한 것이 아님.
- 새 자동 웨이트 계산. 누락 정점 358개는 새로 계산된 인접 웨이트로 보완.
- 분리된 목걸이/스터드는 neck에 강체 웨이트로 연결해 늘어짐 방지.
- 관절 부피 보존 스키닝 사용.

1번 동작
- 새 뼈대를 만든 뒤 OldAsset의 matyr_run_01 FBX만 별도 참고 씬에 불러옴.
- 해당 파일에서 네 발의 궤적/디딤 순서를 읽어 새 체형에 맞게 범위와 타이밍을 조정.
- 기존 뼈를 복제하거나 새 모델에 심지 않음. 원본 애니메이션 액션을 새 뼈에 직접 붙이지 않음.
- 참고용 FBX의 뼈 객체는 샘플링 후 제거.
- 새 관절 계산으로 다리 길이를 유지하며, 자체 키프레임 액션으로 기록.

2번 동작
- 기존 마타나 트리포 애니메이션을 사용하지 않음.
- 대각선 다리의 교대 지지, 짧은 체공, 부드러운 발 회수, 작은 몸통 상하 움직임, 안정된 머리와 꼬리의 지연 움직임을 직접 작성.
- 개가 가볍고 일정하게 뛰는 러닝 트로트를 목표로 제작.
- 웹 참고: University of Minnesota, Trot
  https://vanat.ahc.umn.edu/gaits/trot.html
- 웹 참고: AKC, Built to Last: The Basics of Canine Conformation & Anatomy
  https://www.akc.org/expert-advice/sports/basics-canine-conformation-anatomy/
- 참고 자료는 발 순서와 움직임 성격에 사용. 웹 애니메이션 데이터를 다운로드하거나 복사하지 않음.

검증
- 두 버전 모두 웨이트 미할당 정점 0.
- 전체 97프레임 메시 평가, 반복 시작/끝 정점 오차 0.
- 메시 전체의 최소 바닥 높이: 1번 약 0.00109, 2번 약 0.00100. 바닥면 0 기준 관통 없음.
- 옆면에서 1번 6개 자세, 2번 8개 자세와 최종 비교 카메라를 확인.
- 트리포 뼈 이름이 없는지만 검사한 것이 아니라, 무리깅 시작 파일과 생성 스크립트로 입력 의존성을 기록.
- 게임용 최종 품질 승인, Unity 적용, 다른 동작 제작은 포함하지 않음.
