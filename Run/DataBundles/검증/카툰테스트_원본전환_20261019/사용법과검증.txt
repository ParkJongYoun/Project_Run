카툰 테스트 씬 원본/카툰 전환

대상: Assets/Scenes/Test/Scene_CartoonTest.unity
Play 후 오른쪽 위 '원본 ↔ 카툰' 버튼을 누르면 17종 전체가 전환됩니다.
기본은 카툰이며 현재 표시 모드는 하단 상태에 표시됩니다.
처음 원본으로 전환할 때 17종을 생성하고 이후에는 같은 인스턴스를 재사용합니다.
선택한 몬스터, 확대/회전, 카메라, 대기/달리기 상태와 재생 시점은 전환 중 유지됩니다.

원본은 Assets/ArtBundles/LegacyURP의 기존 모델 프리팹을 사용합니다.
기존 메시/텍스처/아바타/동작을 참조하고, URP 표시 호환용 ProjectRun/CharacterSimple 재질을 사용합니다.
미노의 원본 무기 등 원본 모델의 구성은 유지합니다.
카툰 프리팹 및 카툰 재질에 원본 재질을 연결하지 않고, 전시용 원본 객체를 별도 자식으로 생성합니다.
원본의 기존 Animator Controller와 사운드 이벤트는 전시 복제 객체에서만 끕니다.
원본 및 카툰 자산은 변경하지 않았습니다.

검증 결과
- 원본 첫 전환 시 17종 생성, 카툰 숨김/원본 표시 확인
- 원본/카툰 반복 전환 시 생성 인스턴스 ID 유지 및 중복 생성 없음
- 확대/회전/카메라/재생 시점 유지 확인
- 원본/카툰 x 대기/달리기 각 6초 평가: 신규 경고/오류 0건
- 카툰 프리팹 및 리소스 212개 작업 전후 SHA256 동일
- Editor Play Mode 검증 완료. WebGL 빌드/브라우저 검증은 수행하지 않음
