목장 몬스터·훈련 UI 점검 및 수정 (2026-10-20)

대상
- Assets/Scenes/Scene_LobbyTest.unity
- UIPanel_RanchMonsters / UIPanel_RanchTraining 프리팹
- 제공 시안: DataBundles/UI/목장/몬스터와훈련_우드스타일_스크롤형.png

확인한 기존 문제
- 최신 테이블에는 페코페코지만 두 프리팹에는 에드가 얼굴·전신·훈련 영상이 연결되어 있었다.
- 세로·가로 목록에서 세 번째 카드가 잘렸다.
- 중앙 몬스터 표시 배경은 빈 크림색이었고 카드 이름표와 제목 발바닥이 빠졌다.
- 선택 몬스터와 관계없이 고유 스킬 아이콘은 포링으로 고정되어 있었다.
- 프레임 단순 확대와 일부 9-slice 설정은 테두리·스크롤바 모양을 왜곡했다.

반영
- 기존 프리팹 객체와 씬 참조를 유지하여 배치·이미지를 수정했다.
- 표의 몬스터 ID로 얼굴·전신·스킬 이미지·선택적 훈련 영상을 다시 연결한다.
- 포링·미노타우르스·페코페코 세 카드의 이름과 레벨이 모두 표시된다.
- 제공된 배경/프레임 분리 파츠와 아이콘을 사용하고 배경·이름표·제목 장식을 보완했다.
- 훈련 성장 수치와 완료 상태를 색상으로 구분한다.
- 페코페코는 기존 CartoonRaceLineup의 카툰 캡처 이미지를 사용한다. 전용 2D 원화·훈련 영상은 새로 제작하지 않았으며, 훈련 화면에서는 해당 이미지의 이동·상하 동작을 사용한다.
- 포링·미노타우르스는 기존 전용 훈련 영상을 유지한다. 에드가 원본은 보존한다.
- 현재 세 카드는 전부 표시되므로 스크롤 화살표와 손잡이를 비활성화한다. ScrollRect와 레일은 유지하며 콘텐츠가 넘치면 조작을 활성화한다.
- 재생성 메뉴도 기존 프리팹을 수정하도록 바꿔 동일 연결 문제가 재발하지 않게 했다.

Unity Play 검증
- 1920x1080 및 1280x720에서 실제 Game View 캡처 확인.
- 페코페코 이름·전신·고유 스킬 아이콘·스킬 상세 내용 일치.
- 두 프리팹의 얼굴·전신 누락 0개, Missing Script 0개.
- 몬스터 조회와 훈련 대상 선택 독립, 경기 출전 선택 -1 유지.
- 미노타우르스 훈련 영상 프레임 진행 확인.
- 훈련 중 다른 카드 선택 비활성화, 뒤로가기로 취소하면 성장 없음.
- 페코페코 훈련 완료: Lv.5, 스피드 250→280, 경험치 80→100, 후천 패시브 획득.
- 다른 두 몬스터는 Lv.4·스피드 보너스 0 유지.
- 완료 후 훈련 재실행 차단 및 출전 조건 충족 확인.
- 스킬 상세 열기/닫기와 목장 복귀 확인.
- 관련 스크립트 컴파일 오류 없음. 기존 Unity AI 서비스 NoSubscription 로그는 이 UI 작업과 별개다.
- 완료 후 에디터는 Scene_LobbyTest 편집 모드, 기존 1920x1080 Game View 설정으로 복구했다.

검증 범위
- Unity Editor의 실제 실행·저장된 프리팹을 검증했다. 이번 작업에서 WebGL 재빌드나 브라우저 실행은 수행하지 않았다.
- 시안의 레이아웃과 제공된 개별 파츠를 반영했다. 배경은 기존 훈련장 원화, 페코페코는 기존 카툰 캡처를 사용하므로 통합 시안의 그림과 픽셀 단위로 동일한 구현은 아니다.
- 최종 화면 PNG는 이 폴더에, 수정 전·중간 캡처는 작업기록에 분리했다.
