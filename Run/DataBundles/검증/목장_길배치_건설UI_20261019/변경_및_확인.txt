목장 길 배치·건설 UI 변경 — 2026-10-19

대상: Assets/Scenes/Scene_LobbyTest.unity

변경
- 고정 각도 유지. 줌은 6.2 / 6.6 / 7.0(시작) / 7.4 / 7.8의 총 5단계.
- 카메라 상하 이동은 현재 줌의 지면 표시 범위를 계산해 울타리 바깥 약 1m를 포함하는 경계로 제한.
- 후속 요청 반영: 좌우 이동은 이전과 동일하게 시작 지면 중심에서 ±12 범위로 복원. 상하 제한과 줌 5단계는 유지.
- 시설 배치는 실행 중 메모리에서만 유지. 기존 저장값을 읽거나 새 위치를 저장하지 않음.
- 시작 배치: 좌우로 연결된 흙길 20칸, 몬스터 축사 1개, 먹이창고 1개.
- 흙길을 1×1 건설 항목으로 추가. 길 마스크로 잔디 위 흙길을 표시하고 접한 칸 사이의 이음새를 제거.
- 몬스터의 경로 탐색을 연결된 길의 상하좌우 칸으로 제한. 이동·대기 애니메이션 유지.
- 건설 중 기존 하단 메뉴를 숨기고 왼쪽 건설·닫기, 오른쪽 6개 시설 카드와 페이지 이동으로 표시.
- 시설 11종 아이콘은 지정된 트리포 입력원화와 동일한 원본을 연결. 흙길 아이콘은 실제 길 텍스처 사용.
- 재화 표시는 계속 제거 상태 유지. 확장 구역과 환경 모델은 유지.

확인
- C# 컴파일 완료. 목장 셰이더 3종 오류 없음.
- 카탈로그 12종의 모델·아이콘 참조가 모두 연결됨.
- 초기 배치 22개: 길 20개, 축사 1개, 먹이창고 1개. 겹침·영역 이탈 없음.
- 길 마스크의 활성 칸 20개 확인.
- 씬과 UI 프리팹 저장 완료.
- 에이전트가 Play 실행·게임 플레이 테스트·빌드를 수행하지 않음.
- 저장 이후 읽기 확인 도중 사용자의 Unity가 Play 상태로 전환된 것을 확인하여 추가 에디터 조작 중단.
- 콘솔에 기존 Unity AI NoSubscription 메시지가 남아 있으나 변경 코드·셰이더의 오류는 아님.
