마타 리깅 2종 달리기 비교 (2026-10-20)

열기: 마타_기존뼈와새리깅_달리기비교.blend
비교 씬: Matyr_Two_Rig_Run_Comparison
Blender 화면 위에 마우스를 놓고 Space로 재생/정지.
30fps, 1~20 프레임을 반복. 21프레임은 1프레임과 같은 종료점 검증용이며 재생 범위에서 제외.

왼쪽 / 1 기존 뼈 사용
- 제공된 Tripo의 38개 뼈와 기존 웨이트 유지.
- OldAsset 마타 달리기 파일 자체의 관절 방향을 새 모델에 대응시켜 키프레임으로 기록.
- 원본과 다른 앞다리 이름, 추가 관절, 긴 꼬리를 구분해 연결.

오른쪽 / 2 뼈 제거 후 새 리깅
- 복사 메시에서 부모/Armature modifier/38개 기존 웨이트 그룹 제거 후 시작.
- 기존 마타의 해부학적 관절 구조와 새 모델 관절 위치를 참고해 독립 뼈 25개 생성.
- 완전히 새 자동 웨이트 계산. 누락된 358개 정점은 새로 계산된 인접 정점 웨이트로 보완.
- 목걸이의 분리된 490개 정점은 새 neck 뼈에 강체 웨이트로 보정.
- Tripo 기존 웨이트를 새 리깅에 복사하지 않음.
- 관절 위치 가이드로 기존 Tripo 뼈 위치를 참고했으므로, 무리깅 메시를 입력받아 관절을 자동 추정하는 범용 도구의 검증은 아님.

검증
- 기존 모델 FBX와 달리기 FBX는 같은 뼈 이름이어도 기준 자세가 다름을 확인.
- 모델 파일에 동작 키만 바로 지정하면 방향이 어긋나므로, 최종본은 달리기 FBX 자체의 뼈대에서 움직임을 읽어 이전.
- 두 메시 모두 웨이트 미할당 정점 0개.
- 1~21 전 프레임 바닥 높이 검사 후 버전별 일정 높이 보정.
- 반복 끝점 메시 오차: A 약 0.00000054m, B 약 0.00000023m.
- 한글 라벨/색상 발판/비교 카메라 구성. 텍스처와 한글 폰트는 blend 안에 포함.
- 입력 FBX/OldAsset/Unity 게임 에셋 변경 없음.

상태와 한계
- 달리기 이전과 새 리깅 재생을 비교하는 시험본이다. Unity 적용이나 게임용 최종본이 아니다.
- 발 미끄러짐, 접지 구간, 어깨/골반 웨이트, 꼬리 실루엣은 추가 수작업 보정이 필요하다.
- 귀/입 독립 애니메이션, 나머지 8개 동작, Unity 임포트는 이번 검증에 포함하지 않는다.
- 초기 잘못된 자세 이전 액션은 실행 중 보정되었고 최종 비교 씬은 Corrected 액션을 사용한다.
- 재생성은 작업기록의 달리기_이전과새리깅.py → 관절방향_보정.py → 비교화면_검수와저장.py 순서. 첫 스크립트는 이전 사전검토 blend의 Matyr_Feasibility_Check 씬에서 실행한다.
