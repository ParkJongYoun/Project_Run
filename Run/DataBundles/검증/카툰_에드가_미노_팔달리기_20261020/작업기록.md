# 카툰 달리기 팔 동작 수정

- 에드가: 오른팔의 반 주기 뒤 동작을 좌우 반사하여 왼쪽 어깨·상완·전완·손목의 회전만 새 클립에 기록했다.
- 미노타우루스: 원래 다리 동작의 박자를 따라 양팔이 반대로 흔들리도록 상완·전완 회전만 새 클립에 기록했다. 팔꿈치를 굽히고 약간의 굽힘 변화를 추가했다.
- 전용 Run_FreeArms 애니메이션을 각 독립 카툰 프리팹과 Scene_CartoonTest 전시에 연결했다. 미노의 기존 팔 미리보기 참조도 새 클립에 연결하고 기존 배속 4.4를 유지했다.
- 두 대상 모두 원래 클립과 길이·루프 설정이 같으며 팔 이외 곡선 변경은 0개다. 각각 팔 회전 곡선 16개를 수정했다.
- 기존 Run.anim 파일은 수정 전 백업과 SHA256이 같다. OldAsset 및 원본 비교 모드의 클립은 수정하지 않았다.
- 정면·측면 4개 위상 렌더를 검수했다. Play에서 달리기 재생 및 원본→카툰 전환을 확인했다.
- 수정 전 씬·프리팹·클립은 수정전 폴더에 보존했다.
