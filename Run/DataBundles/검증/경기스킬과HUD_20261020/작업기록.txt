Project Run 경기 스킬과 HUD 수정
작업일: 2026-10-20
실제 작업 프로젝트: C:/Project_Run/Run (안내된 D:/Project_Run/Run은 이 환경에 없음)
대상: Scene_OvalToon, UIPanel_DemoRace

적용 완료
- 고정 6종 각각 노말·레어·유니크 스킬을 연결했다.
- 노말 3회, 레어 2회는 UI 사건만 발행하며 유니크는 각 1회 실제 가속을 적용한다.
- 선택 플레이어블만 진행률 60% 이후 기존 7초 영상을 재생한다. 다른 주자는 별도 컷신 없이 띠와 기존 주자 효과를 표시한다.
- 우측 상단의 재사용 슬롯 4개에 얼굴·주자 번호·이름·스킬명·등급을 표시한다.
- 노말 은청색, 레어 보라색, 유니크 금색. 오른쪽에서 진입하고 오래된 띠는 위로 이동하며 사라진다.
- 알림 집중 시 최소 읽기 시간 뒤 오래된 띠를 먼저 퇴장시킨다. 정지·영상 중 알림 시간도 멈추고 결과·재경기·패널 종료 시 큐를 비운다.
- 실제 경기 프리팹에서 512px 얼굴 캡처 6종을 만들었다. 바포메트 주니어·알파카는 머리 소켓을 사용했다.
- 목록·띠·하단 얼굴은 같은 얼굴 리소스를 공유한다. 하단 초상의 과도한 배율을 없앴다.
- 연출 ON 버튼과 해당 HUD 직렬화 필드를 제거했다. 영상 오류·건너뛰기 처리는 유지한다.
- 중계 영역은 286×63, 기본 15px·강조 16px, 20px 줄 간격과 RectMask2D를 사용한다. 배속 버튼과 분리했다.
- 순위 목록은 카운트다운 동안 열리고 START 사건에서 닫힌다. 목록 아이콘으로 다시 펼치거나 접는다.
- 진행바에 6종의 고정 번호와 색을 표시한다. 가까운 번호는 2줄로 분산하고 같은 줄 최소 간격을 확보한다.
- 색 원 위를 흰 테두리가 덮던 자식 순서를 수정했다. 선택 화살표는 진행바 위에 고정하여 다른 번호를 가리지 않는다.
- 선택 주자의 머리를 따라 금색 테두리·청록색 역삼각형이 이동한다. 글자와 입력 차단은 없다. 화면 밖·영상·완주 뒤에는 숨긴다.

데모 역전
- 시작 시 82% 확률로 선택 주자의 역전 보정 여부를 정해 경기 입력에 저장한다.
- 보정이 있는 주자의 유니크 발동 이후, 진행률 70%부터 남은 시간·선두 간격·피로·코너 이동거리로 후반 가속을 계산한다.
- 보정 중에는 앞 대열을 더 일찍 살펴 빈 레일을 찾는다. 충돌·추월·완주 판정은 기존 고정 시간 간격 계산을 사용한다.
- 위치·순위·완주 시각을 직접 변경하거나 승리를 확정하지 않는다. 확률은 승률의 보장이 아니다.
- 선택 주자의 영상과 연결되는 기본 유니크는 11%·9초의 데모 설정을 사용한다. 표의 종별 유니크 속도비·지속시간은 상대 출전 시 적용한다.

최종 경기 계산 검증
- 미훈련: 각 36회, 총 108회.
  포링 28/36 승리(77.8%), 미노타우르스 29/36(80.6%), 페코페코 28/36(77.8%).
  승리 시 마지막 선두 추월 평균 진행률: 95.4%, 92.9%, 93.2%.
- 훈련 완료: 각 18회, 총 54회.
  포링 14/18(77.8%), 미노타우르스 15/18(83.3%), 페코페코 14/18(77.8%).
  승리 시 마지막 선두 추월 평균 진행률: 93.9%, 91.1%, 91.8%.
- 총 162회 모두 6종의 노말 3·레어 2·유니크 1회 발동을 확인했다.
- 같은 입력을 한 스텝씩 또는 두 스텝씩 진행했을 때 순위·완주 시각·유니크 횟수가 동일했다.
- 노말·레어 발행을 제거한 동일 입력 경기와 최종 결과가 동일했다.
- 선택 주자 유니크의 가장 이른 발동은 60.0001%였다.
- 위 값은 고정된 검증 시드 표본의 측정 결과다.

실제 Unity Play 검증
- 포링·미노타우르스·페코페코 세 선택을 모두 실제 진입 경로로 검증했다.
- 목록 자동 접기·다시 펼침·재접기, 6개 진행 번호, 서로 다른 색, 중계 마스크·버튼 비중첩, 얼굴 연결, 선택 표식 표시를 확인했다.
- 실제 영상 첫 프레임 디코드, 영상 중 경기 계산 정지, 영상 종료 및 건너뛰기 후 복귀를 확인했다.
- 실제 재생/건너뛰기 후 결과가 같은 입력의 독립 계산과 일치했다.
- 결과 이동·재경기에서 영상 및 스킬 띠가 초기화되고 새 경기의 결과 건너뛰기도 독립 계산과 일치했다.
- 최종 띠 크기·폰트·표시 순서 변경 뒤 미노타우르스로 동일 HUD 및 재생 검사를 다시 통과했다.
- Unity 코드 재로딩 중 실행 중인 비직렬화 경기 상태가 사라지는 에디터 상태가 관찰됐다. 새 경기 초기화 후 검사했고, 최종 화면 검사 동안만 어셈블리 재로딩을 보류했다.
- Unity AI 패키지의 기존 NoSubscription 메시지는 이번 경기 코드 오류와 구분했다.
- 웹 빌드 생성 및 실제 브라우저 기기 검증은 이번 작업에서 수행하지 않았다.
