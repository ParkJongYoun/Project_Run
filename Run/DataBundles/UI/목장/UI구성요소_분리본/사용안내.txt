목장 UI 구성요소 분리본
제작 기준: UI참고용.png의 크림색·갈색 테두리와 그림체를 참고한 재제작
생성 방식: 내장 image_gen. 요청 요약: UI만 남기고 배경·문구·수치를 제거, 레이아웃과 아이콘을 투명 PNG로 분리.

구성
- 아이콘/: 목장, 포링, 건설, 훈련, 트로피, 골드, 보석, 수첩, 설정 톱니, 잠금, 완료, 상태 망치, 더하기, 알림점 — 14종
- 레이아웃/: 목장 정보, 재화 바, 원형 버튼, 상태 말풍선, 확장 표지판, 공통 메뉴 버튼, 나무 받침판 — 각 배경/프레임 한 쌍, 7종 14파일
- 레이아웃/전체배치_글자와아이콘없음_1280x720.png: 레이아웃만 배치한 투명 PNG
- UI_전체_글자없음_1280x720.png: 레이아웃과 아이콘을 조립한 투명 PNG
- 00_UI조립_미리보기.png: 문구를 얹은 배치 확인용 이미지. 체크무늬는 이 미리보기에만 포함
- 01_분리파츠_미리보기.png: 모든 아이콘과 배경/프레임/조립 비교
- 파츠목록.json: 개별 파일명과 실제 픽셀 크기
- 배치좌표.json: 원본 1672×941 기준 좌상단 좌표. 1280×720 변환 비율 포함
- 작업기록/: 생성 원본, 전체 생성 프롬프트, 분리 도구와 투명도 검사

사용
1. 같은 이름의 배경과 프레임을 동일한 위치·크기로 놓고, 배경 위에 프레임을 겹칩니다.
2. 아이콘을 그 위에 별도 이미지로 배치합니다. 목장/골드/보석/잠금/상태 아이콘은 여러 위치에서 재사용합니다.
3. 버튼 이름·레벨·재화 수치는 별도 텍스트로 넣습니다. 실제 파츠 PNG에는 문구가 없습니다.
4. 메뉴 공통 버튼은 5개 메뉴에서 재사용합니다. 재화 바의 작은 사각 추가 버튼 영역은 바 프레임에 포함되고, 더하기 기호는 별도 아이콘입니다.
5. 각 아이콘은 비율을 유지해 축소해서 사용합니다. 프레임/배경은 같은 캔버스 크기로 짝지어져 있습니다.
6. 자료 제작과 PNG 조립 확인까지 완료했으며 Unity 임포트·프리팹 연결·9-slice 설정은 이 작업 범위에 포함하지 않았습니다.

검수
- 14개 아이콘 및 14개 배경/프레임 PNG의 실제 투명 알파 확인
- 7개 배경/프레임 쌍의 캔버스 크기 일치 확인
- 밝은/어두운 배경의 파츠 미리보기와 1280×720 조립 미리보기 확인
- 기존 UI참고용.png와 목장 경로의 기존 자료는 보존
