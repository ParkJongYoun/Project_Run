목장 몬스터 수첩·훈련소 UI 수정 및 검증 — 2026-10-20

대상
Scene_LobbyTest에 연결된 UIPanel_RanchMonsters / UIPanel_RanchTraining 프리팹.
참조 시안: DataBundles/UI/목장/몬스터와훈련_우드스타일_스크롤형.png

확인한 기존 차이
넓고 빈 흙바닥 배경, 다른 포링 형태, 전신 3D 페코페코를 축소한 카드,
늘어난 타원 게이지와 스크롤 레일, 지나친 카드 간격, 잘못된 능력치 색상,
시안과 다른 별도 배경을 재생하는 훈련 영상이 있었다.

수정 내용
1. 1280×720 기준 좌표로 수첩의 세로 카드·중앙 몬스터·능력치·기록·스킬을 재배치했다.
2. 파란 지붕, 분수, 꽃이 있는 목장 배경과 낮고 넓은 포링을 적용했다.
3. 훈련소의 가로 카드, 나무 장애물 배경, 효과·조건·안내·시작 버튼을 재배치했다.
4. 능력치 게이지를 파랑·빨강·주황·보라·초록의 둥근 막대로 바꾸었다.
5. 간판, 랜턴 기둥, 카드 테두리, 짧은 금색 스크롤 손잡이, 글꼴과 아이콘을 조정했다.
6. 페코페코 전용 2D 전신·얼굴을 수첩, 훈련, 이름표, 고유 스킬에 연결했다.
7. 훈련은 공통 장애물 배경 위에서 선택 몬스터의 투명 스프라이트를 점프·회전·크기 변화로 움직인다.
   이전 배경 영상 참조를 두 프리팹에서 해제했으며, 원본 영상·원화 파일은 보존했다.
8. 세 카드가 모두 보일 때도 화살표와 스크롤 손잡이로 대상을 선택할 수 있다.
9. 프리팹 내부 객체를 수정하고 필요한 레이어를 추가했다. 다른 씬 작업을 저장하는 빌드 메뉴는 실행하지 않았다.

검증 결과
Unity 6000.3.23f1, Scene_LobbyTest 실제 Play 모드.
50개 동작 검증 PASS. 세부 로그는 최종검증/동작검증.txt.
- 세 몬스터의 얼굴·전신·이름·능력치 및 스킬 상세 3종.
- 수첩·훈련·경기 확정 대상의 독립성.
- 화살표·스크롤 손잡이·뒤로가기·목장 입력 차단 및 복구.
- 각 몬스터의 훈련 애니메이션, 훈련 중 선택 잠금, 중도 복귀 취소.
- 7초 훈련 완료: Lv.5, 스피드 +30, 경험치 +20, 후천 패시브.
- 중복 성장 방지, 다른 몬스터 성장 미변경, 수첩 성장 결과 반영.
검증 중 변경한 유저 데이터는 finally에서 원래 값으로 복구했다.

1280×720 및 1920×1080의 실제 Game View 캡처를 검수했다.
1920×1080에서 수첩 버튼 9개, 훈련 버튼 7개의 중심점 UI Raycast가 각 버튼에 도달함을 확인했다.
두 화면의 활성 텍스트에서 높이 초과 없음.
최종 화살표 위치·카드 폭 조정 뒤에도 전/후 선택과 영상 참조 해제를 다시 확인했다.
수정 코드의 컴파일 오류 0건.

확인 범위
이번 검증은 Unity Editor Play 모드다. WebGL 새 빌드는 수행하지 않았다.
콘솔에는 별도 목장 3D 몬스터의 발소리·사운드 AnimationEvent 수신자 오류와
Unity 이미지 생성 서비스의 기존 NoSubscription 로그가 있었다. 이 UI 작업과 분리해 기록한다.
원본 시안의 글자를 포함한 단일 그림을 붙인 결과가 아니라 개별 요소로 동작하는 UI이며,
새 배경·캐릭터 소재의 세부 붓질까지 원본과 동일한 픽셀 복제라고 주장하지 않는다.
