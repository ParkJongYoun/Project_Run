목장 몬스터·훈련 UI 수정 완료 — 2026-10-20

반영 내용
- 훈련 시작 버튼: 시안 형태의 녹색 사각 프레임, 별도 배경, 흰 날개와 흰 글자 적용.
- 목장 복귀 버튼: 금색 테두리와 갈색 내부로 수정. 두 화면에 공통 적용.
- 훈련 대상 목록의 양쪽 화살표 제거. 카드 선택과 스크롤바 유지.
- 패널 뒤 장식 배경 제거. 검정 48% 반투명 막을 적용해 실제 목장이 보이도록 수정.
- 포링·미노타우르스·페코페코별 훈련장면 3장과 Comfy 시작 이미지 3장 제작.
- 대상 선택에 맞는 훈련장면 연결. 이전 단일 전신 흔들기 연출 제거.
- 추후 영상 프레임을 기존 로비 애니메이션 플레이어에 연결할 수 있도록 슬롯 유지.

산출물
캐릭터별_훈련이미지: 확정 PNG 6장 및 사용안내.txt.
훈련버튼_수정소재: 버튼 프레임과 흰 날개 아이콘.
작업기록의 이미지생성_프롬프트.json: 생성 프롬프트.
작업기록의 최종검증: 이미 확보한 화면과 동작 확인 기록.

상태
코드 및 두 UI 프리팹에 반영 완료. 사용자 요청 이후 추가 플레이 테스트는 수행하지 않음.
새 훈련 영상은 아직 생성하지 않았으며, 추후 Comfy 제작용 시작 이미지와 연결 자리를 준비한 상태.
