경기장 UI 스타일 비교 시안 · 2026-10-20

요청 범위: 기존 로비 경기장의 달리는 몬스터 분위기를 유지하며 로비 테스트 목장과 첨부 우드 UI에 어울리는 여러 스타일을 비교한다.
제작: 내장 image_gen 사용. 정적인 외형 제안 4종이며 게임 씬, 코드, 프리팹, 기존 에셋은 수정하지 않았다.

01_경기장_우드프레임형.png: 첨부한 몬스터/훈련 UI와 통일하기 쉬운 목재 외곽 프레임, 우측 경기 정보 패널.
02_경기장_탁트인목장형.png: 풍경과 트랙을 넓게 보여주는 목장 전경, 하단 정보 띠. 사용자가 선호한 주행 구경에 가장 적합한 방향으로 추천.
03_경기장_축제경기장형.png: 파란 천 배너, 관람석, 깃발로 대회 분위기를 강조한다.
04_경기장_수첩결합형.png: 오른쪽 종이 수첩에 코스 도식과 메모를 모아 배치한다.

공통 검수: 네 이미지 모두 전체 화면 구도, 목장으로/경기장/수첩/프론테라컵/참가 조건/출전 준비 문구, 설정 아이콘, 흙 트랙과 몬스터 6마리 표시를 육안 확인했다. 현재 플레이어블 기준에 맞춰 포링·미노타우르스·페코페코를 포함했고 추가 주자 예시는 루나틱·스모키·세비지로 설정했다. 참고 이미지의 에드가 선택 구성을 새 기준으로 채택하지 않았다.
제약: 캐릭터의 정확한 모델 비율, 달리기 방향과 트랙 경로, 파츠 분리 및 해상도별 Safe Area는 실제 구현 검증 대상이다. 화면의 6종은 비교용 예시이며 무작위 출전 규칙을 바꾸지 않는다. 실제 씬 캡처나 동작 구현 결과가 아니다.
