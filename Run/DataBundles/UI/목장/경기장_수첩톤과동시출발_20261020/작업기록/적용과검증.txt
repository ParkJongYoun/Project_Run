경기장 수첩 톤 및 동시 출발 미리보기
작업일: 2026-10-20

요청
첫 번째 참고 이미지의 몬스터 수첩에 맞춰 경기장 화면의 프레임, 제목, 수첩·설정·출전 준비 버튼을 통일한다.
경기장 그림 위의 미리보기 주자가 같은 출발선에서 함께 출발한 뒤 서로 다른 속도로 간격을 벌리도록 한다.
다른 채팅의 Unity 에디터 검증 종료 및 에디터 재생·컴파일 종료를 확인하고 적용을 시작했다.
이 환경의 실제 Unity 경로는 C:/Project_Run/Run이다. 지침에 기재된 D:/Project_Run/Run은 존재하지 않았다.

적용 완료
- 몬스터 수첩의 기존 아트를 재사용했다. 적갈색 제목판, 발바닥 장식, 목재 기둥·랜턴, 금색 테두리의 갈색 버튼, 양피지 백판과 얇은 프레임을 연결했다.
- 1280×720 기준, 0.94 배율과 Safe Area를 사용하고 프레임 안으로 내용을 배치했다.
- 타이틀은 경기장 패널의 제목을 의미한다. Scene_Title에는 수정하지 않았다.
- 제목·출전 준비 버튼의 일반 텍스처/스프라이트 연결 누락을 정상 스프라이트 연결로 교체했다.
- 출전 선택 창 내부의 훈련 이동·출전 확정 버튼에도 배경과 프레임을 별도로 연결했다. 기존 수첩·출전 선택 창의 디자인과 기능 연결을 유지했다.
- 미리보기 이미지 6개 준비 후 공통 시계를 시작한다. 1.2초 준비 후 같은 코스 거리의 서로 다른 6개 레인에서 출발하고 1.4초 동안 가속한다.
- 주자별 미리보기 속도 배율은 0.95, 1.04, 1.09, 0.90, 1.14, 1.00이다. 기본 한 바퀴 시간은 38초이며 가장 느린 주자 완주 후 페이드로 다음 출발을 연결한다.
- 주행 코스·8방향 스프라이트·원근 크기·깊이 정렬을 유지했다. 패널을 닫으면 준비를 취소하고 재입장 때 시각·진행 시간을 초기화하며 기존 주자 객체를 재사용한다.

범위
기존 2D 경기장 미리보기용 6종 스프라이트를 재사용했다. 정식 Scene_OvalToon의 편성, 스탯, 경기 판정, 필살기, 육성 보상은 변경하지 않았다.
출발 대기 때에는 트랙 폭과 사선 원근으로 앞뒤 주자의 그림이 일부 겹친다. 출발 후 속도 차이로 점차 분리된다.
RanchArenaReferenceStyle.Refresh는 경기장 프리팹만 저장한다. 로비 씬을 저장하지 않는다.
Tools > Project Run > Ranch > Match Arena To Monster Notebook으로 같은 스타일을 다시 적용할 수 있다.
기존 Build Arena UI에도 이 스타일 적용을 연결했다.

실제 검증
- Unity 에디터 1920×1080에서 실제 UI를 캡처해 검수했다.
- 첫 로딩 도중 즉시 닫고 다시 열어도 6개 이미지가 준비되고 공통 출발이 유지됐다.
- 출발 대기 시 6종의 진행 거리 차이 0, 위치는 서로 다른 6개 레인으로 확인했다.
- 8초 거리 차이 0.0385바퀴, 24초 거리 차이 0.1396바퀴로 증가했다.
- 가장 느린 주자도 루프 초기화 전에 한 바퀴를 완주했다.
- 수첩 열기·닫기, 설정 열기·닫기, 출전 선택·취소, 훈련 필요 버튼, 출전 가능 버튼, 목장 복귀 및 재입장을 확인했다.
- 출전 가능 버튼 검증에서만 메모리상의 임시 레벨·스피드를 올렸고, 검증 종료/실패 시 원래 데이터로 복구한다. 실제 출전은 실행하지 않았다.
- 미리보기·팝업 탐색이 유저 진행, 능력치, 확정 출전 대상 데이터를 바꾸지 않는 것을 JSON 비교로 확인했다.
- 반복 열기 이후에도 주자 객체는 정확히 6개이며 시간이 0으로 초기화된다.
- 제목/버튼의 별도 배경·프레임 참조 및 훈련 이동/출전 확정의 표시 이미지 참조를 확인했다.
- Scene_LobbyTest, UIPanel_RanchMonsters, UIPanel_RanchTraining 파일은 시작 해시와 동일했다.
- 수정 C# 공백 검사 및 Unity 컴파일을 통과했다. 기존 Unity AI 서비스의 NoSubscription 로그는 별도 환경 오류로 남아 있다.
- 전체 결과는 검증/동작검증.txt에 기록했다.

검증 한계
웹 빌드와 실제 브라우저 재검증은 수행하지 않았다. 이 작업의 결과는 Unity 에디터 및 저장된 프리팹 기준이다.
검증 중 스크립트 재로딩이 Play 진입과 겹쳐 검증 도구의 관리자 참조가 초기화된 실행은 제외하고, 재생을 완전히 재시작한 실행에서 통과를 확인했다.
