로비 테스트 경기장 · 우드 UI와 수첩 배치
작업일: 2026-10-20

적용
- Scene_LobbyTest의 경기장 버튼에 UIPanel_RanchArena 프리팹을 연결했다.
- 사용자가 선택한 4번 시안의 왼쪽 미리보기·오른쪽 코스 정보·오른쪽 아래 출전 준비 배치를 사용했다.
- 외곽 나무 프레임, 빨간 제목판, 랜턴, 발바닥, 크림색 패널과 초록 버튼은 기존 몬스터·훈련용 RanchCollection 개별 파츠를 재사용했다. 배경과 프레임은 별도 Image로 유지한다.
- 기존 로비의 arena 배경과 UIItem_ArenaExhibition의 흙 트랙 경로·8방향 달리기 스프라이트를 사용한다. 미리보기는 포링·미노타우르스·스모키·세비지·루나틱·에드가 6종이며 실제 경기 참가 명단과는 별개다.
- 주자는 38초 기준 순환, 넓은 간격, 원근 크기로 표현한다. 기존 로비의 주행 설정 기본값은 보존했다.
- 미리보기 즉시 닫기·재열기에서 중단된 비동기 로딩이 이어지도록 주행 표시 준비 수명을 보완했다.
- 출전 준비는 현재 플레이어블 포링·미노타우르스·페코페코를 표시한다. 공통 테이블의 출전 조건과 추천 전술을 사용하고, 확인 시에만 선택을 저장해 Scene_OvalToon으로 연결한다. 조건 미달 시 기존 훈련 화면으로 이동한다.
- 수첩 상세, 소리 설정, 목장 복귀를 연결했다. 닫으면 목장 UI·카메라·건설 입력을 복원한다.

검증
- Unity 6000.3.23f1 에디터에서 컴파일 확인.
- 1920×1080에서 첫 배치 확인 후 여백·선택 표시·이미지 마스킹을 보정했다.
- 최종 1280×720 Play에서 15개 동작 검증을 모두 통과했다. 세부 결과는 검증/동작검증.txt.
- 즉시 닫기·재열기, 6종 로드와 주행 이동, UI 입력 차단/복원, 단일 EventSystem, 훈련 조건, 선택 취소 시 데이터 보존, 수첩, 설정, 실제 Scene_OvalToon 진입을 확인했다.
- 최종 화면·출전 팝업·수첩·실제 경기 진입 PNG와 72개 주행 프레임을 기록했다. 주행 WebP는 실제 캡처 간격을 사용하며 약 7.4초다.
- 검증에 사용한 임시 훈련 값은 종료 시 복원했다. 작업 종료 상태는 Scene_LobbyTest, Play 종료, 씬 저장 완료다.
- 웹 빌드는 이번 작업에서 실행하지 않았다.
