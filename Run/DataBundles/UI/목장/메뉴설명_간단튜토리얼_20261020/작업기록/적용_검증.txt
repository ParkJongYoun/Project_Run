목장 메뉴 설명형 튜토리얼
2026-10-20

적용
- 첫 인사를 한 장으로 줄이고 기존 캐릭터·로비 스타일 대화창 유지.
- 첫 인사 뒤 몬스터 → 시설(건설) → 훈련 → 경기장의 네 메뉴만 설명.
- 해당 메뉴 위치만 밝게 두고 나머지 화면을 딤드 처리.
- 각 메뉴 위에 목재 제목판·양피지 백판·별도 프레임의 작은 설명창과 아래쪽 포인터 표시.
- 설명창의 다음·완료로 진행. 실제 메뉴 클릭, 배치, 훈련, 출전을 요구하지 않음.
- 밝은 메뉴 영역에도 투명 입력 차단막을 두어 실제 메뉴 실행 방지. 키보드 선택도 설명 진행 버튼에 고정.
- 전체 스킵 버튼과 이전의 클릭 유도, 화면별 첫 방문, 훈련 완료, 출전 준비 안내 제거.
- 네 설명이 끝나면 딤드·입력 차단을 해제. 같은 체험 재진입은 반복하지 않고 새 체험에 재시작.
- UIPanel_RanchGuide 프리팹과 Scene_LobbyTest 연결 갱신.
- 개발 규칙 15번 및 AGENTS.md 요약에 이번 합의를 우선 기준으로 반영.
