- 목장은 새 Idle/Walk/Clap을 사용하며 기존 길 이동·시설 방문 코드를 유지한다.
- 로비와 경기 모두 기존 확정 6종이 각 1마리씩 등장한다. 출전 선택·능력치·필살기 ID는 유지한다.
- 얼굴 512×512와 전신 1024×1024를 별도로 렌더링해 정보·훈련 목록·출전 선택·경기 HUD·결과 화면의 이미지를 갱신했다.
- 기존 미노와 신규 미노 원본·전시 프리팹·재질·텍스처는 보존했다. 기존 훈련/필살기 MP4는 이번 작업에서 재생성하지 않았다.
- 이후 Tools/Project Run/Cartoon monsters/Sync race lineup from showcase를 실행해도 새 미노를 사용한다.

2. 튜토리얼
- 기존 UIPanel_DemoLobby와 Mgr_Guide의 안내 흐름을 참고해 새 목장 패널에 연결했다.
- 사용자 첫 첨부의 중앙 캐릭터+하단 대화창 구성을 적용했다. 두 번째 첨부의 환영 포즈를 내장 image_gen으로 투명 PNG로 정리했다.
- 별도 UIPanel_RanchGuide 프리팹, 팝업 레이어 Canvas, Safe Area, 1280×720 기준을 사용한다.
- 대화 배경·금색 프레임은 서로 다른 이미지이며 분홍 이름표와 타이핑·클릭 진행·전부 스킵을 제공한다.
- 흐름: 첫 인사 → 몬스터 버튼 강조 → 몬스터 첫 방문 설명 → 목장 복귀 후 훈련 버튼 강조 → 훈련 설명 → 실제 훈련 완료 축하 → 경기장 안내 → 수첩 강조 → 출전 선택 설명.
- 대화 중 목장 조작을 막고 종료 시 해제한다. 버튼 강조는 다른 메뉴 이용을 막지 않는다.
- 안내 상태는 Mgr_Guide의 실행 중 메모리에서만 관리한다. 일반 재진입에서는 반복하지 않으며 새 체험에는 방문 상태를 초기화한다. 전부 스킵은 같은 실행 동안 유지하고 새 Play에는 다시 안내한다.
- 신규 UI 재생성 메뉴: Tools/Project Run/Ranch/Build character tutorial.

4. 후속 수정: 로비 신규 미노 걷기 충돌
- 사용자가 지적한 대기 자세로 미끄러지는 현상을 실제 로비 실행에서 재현했다. 이전 검증은 Walk 연결을 확인했지만 최종 렌더 프레임의 보행까지 확인하지 못했다.
- Sys_RanchResident가 Update에서 걷기 포즈를 평가한 뒤, 신규 미노의 기본 Animator Controller가 Idle 포즈로 다시 덮어쓰고 있었다.
- 목장 애니메이션 그래프가 작동하는 동안 기본 Controller를 분리하고, 컴포넌트 비활성화 시 원래 Controller를 복원하도록 수정했다. 원본 클립·프리팹·외형·이동 경로와 속도는 변경하지 않았다.
- 수정 후 실제 로비 프레임 188개에서 양발의 번갈아 내딛기를 측정했다. 좌/우 발의 모델 기준 전후 이동 폭은 각각 0.3826 / 0.3684다.
- 실제 이동, 조작 차단 시 대기 전환, 비활성화 시 Controller 복원, 재활성화 시 그래프 재생, 주민 6종의 유효 그래프를 확인했다. 걷기_수정후_검증.txt 결과 PASSED.
- 확대 화면은 검증/12_걷기수정_실제포즈.png에 보관했다. 이번 후속 수정도 Unity Editor에서 검증했으며 웹 재빌드는 수행하지 않았다.
