레이아웃
- 전체화면 크림백판과 우드 외곽 프레임은 별도 이미지입니다.
- 제목판·정보패널·세로카드·가로카드·스킬패널·버튼은 배경과 프레임이 별도입니다.
- 같은 이름의 배경과 프레임은 같은 크기·중심으로 겹쳐 사용합니다.
- 세로/가로 카드의 선택테두리는 선택 상태에서 추가 표시합니다.
- 캐릭터·영상 표시프레임의 안쪽은 투명하며 콘텐츠를 아래 레이어에 넣습니다.
- 세로·가로 스크롤 레일, 손잡이, 위/아래/왼쪽/오른쪽 버튼은 개별 파일입니다.
- 몬스터 화면의 왼쪽 목록은 세로 ScrollRect, 훈련 화면 상단 목록은 가로 ScrollRect 구성용입니다.
- 두 조립배치는 배치 참고 이미지입니다. 실제 게임에는 개별 파츠를 조립합니다.

- 캐릭터 얼굴은 얼굴 이미지만이며 새 목장 카드 프레임은 별도로 겹칩니다.

제작 및 검수 범위
- 승인된 통합 시안을 기준으로 이미지 생성 도구로 가려진 빈 UI 파츠를 복원한 뒤, 파츠 자르기·배경/테두리 분리·알파 정리로 제작했습니다.
- 합본 시안에서 가려진 부분은 재제작되었으므로 시안의 픽셀과 완전히 동일한 추출본은 아닙니다.
- 글자·수치·이름은 PNG에 굽지 않고 Unity 텍스트로 표시하도록 비워 두었습니다.
- 66개 파츠의 크기와 투명도를 확인하고 개별 미리보기 및 두 화면 조립 검수를 수행했습니다.
- 9-slice 값은 초기 참고값이며 실제 표시 크기에서 조정할 수 있습니다.
- Unity 씬·프리팹 연결 및 실제 스크롤 동작 구현은 이번 작업에 포함하지 않았습니다.
- 생성 원본·프롬프트·분리 도구·검수 이미지는 옆 폴더 '몬스터훈련_우드UI_분리작업기록'에 보관했습니다.
