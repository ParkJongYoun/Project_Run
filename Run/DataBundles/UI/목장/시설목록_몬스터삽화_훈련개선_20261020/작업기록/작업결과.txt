완료:
- 시설 하단을 기존 로비 목재 받침과 양피지 메뉴 버튼 자산으로 통일. 배경과 프레임은 별도 레이어, 시설 카드는 별도 9-slice Sprite asset으로 재사용.
- 건설·닫기·페이지 이동·카드 선택과 드래그 배치 흐름 유지.
- 미노타우루스 얼굴/전신을 새 2D 삽화로 교체. 사용자 피드백에 따라 첫 미형 시안은 미채택하고 원래 소 몬스터 얼굴과 단순한 명암으로 수정.
- 얼굴은 수첩 목록·상세 헤더·고유 스킬·훈련 카드에서 공통 사용. 경기 3D 모델·재질은 수정하지 않음.
- 경기 라인업 재생성 도구가 별도 수첩 삽화를 3D 캡처로 덮어쓰지 않도록 보호.
- 수첩 위/아래와 훈련 좌/우 잔여 화살표 GameObject 제거. 세로 스크롤 영역 높이 540으로 확장.
- 수첩 하단 스킬 카드·초상화와 훈련 시작 버튼·영상 창을 목재 프레임 안쪽으로 배치.
- 훈련 중앙에 '훈련중....' 문구와 반투명 백판. 준비/재생 동안 표시하고 완료·중도 복귀 때 숨김.
- 훈련 진행바를 9-slice로 바꾸고 미디어 진행도에 따라 실제 너비를 조정.
- 세 훈련 영상의 프레임을 유지하며 2.5배속 재생용으로 변환: 1024×576 / 60fps / 2.8초 / H.264 yuv420p, faststart.
- 영상 파일 시간축을 변환하여 플랫폼별 VideoPlayer 배속 지원에 의존하지 않음. 원래 24fps / 7초 파일은 영상원본 폴더 보존.
