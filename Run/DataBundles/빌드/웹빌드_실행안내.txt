Project Run 웹 빌드 2종

1. 심사 데모
폴더: 심사데모_WebGL
실행: 해당 폴더의 Play.cmd
흐름: Scene_Title → Scene_Lobby → 출전·전술 확정 → Scene_OvalToon 또는 Scene_2D
Unity 메뉴: Tools > Project Run > Build Web - Game
기존 Tools > Project Run > Demo > Build Review Demo WebGL 메뉴도 같은 데모를 생성합니다.

2. 테스트 씬
폴더: 테스트씬_WebGL
실행: 해당 폴더의 Play.cmd
첫 씬: Assets/Scenes/Test/Scene_TestTitle.unity
버튼: 미노타우루스 외형 테스트 / 타원 경기장·기존 캐릭터 / 프론테라·기존 캐릭터 / 프론테라·카툰 캐릭터
각 씬 우측의 '테스트 목록' 버튼으로 테스트 타이틀에 돌아옵니다.
Unity 메뉴: Tools > Project Run > Build Web - Test Scenes
빌드 전 Assets/Scenes/Test 폴더의 씬을 찾아 타이틀 버튼과 복귀 버튼을 다시 연결합니다.
버튼만 갱신하려면 Tools > Project Run > Test Scenes > Connect scene buttons를 사용합니다.

공통
- Play를 중지하고 열린 씬을 저장한 뒤, Web 플랫폼에서 빌드합니다.
- 두 메뉴는 포함 씬과 첫 씬을 별도로 지정합니다. Editor Build Settings의 전체 목록을 그대로 빌드하지 않습니다.
- UI 설계 기준은 1280×720이며 기존 PC 품질을 유지합니다.
- 게임 화면은 16:9 비율을 유지합니다. 21:9 등 넓은 창에서는 좌우에 여백이 생기며, 좁은 창에서는 상하에 여백이 생깁니다. 창 크기에 맞춰 화면 전체가 들어가도록 조절됩니다.
- 표시 설정 수정 후 기존 브라우저에서는 Ctrl+F5로 새로고침해 주세요.
- Play.cmd는 로컬 웹 서버를 실행합니다. index.html을 더블클릭하지 마세요.
- 데모는 18767~18776, 테스트는 18777~18786 중 사용 가능한 포트를 사용합니다.
- 배포할 때는 각 폴더 안의 index.html, Build, StreamingAssets 및 나머지 웹 파일을 함께 복사합니다.
- 각 폴더의 빌드구성.txt에서 생성 시각과 포함 씬을 확인할 수 있습니다.
- 검증 화면과 빌드 상태는 작업기록/웹빌드_2종에 따로 보관합니다.
