로비 건설 UI 축소·추적 아이콘 적용 기록 (2026-10-20)

대상: C:/Project_Run/Run, Scene_LobbyTest
다른 채팅의 Unity 작업 완료를 확인한 후 로비 에디터 작업을 진행했다.
다른 채팅에서 변경한 캐릭터·경기·폰트·문서는 수정/복구하지 않았다.

적용 완료
- 하단 건설 목록은 1280×720 기준 높이 120, 카드 143×108로 축소했다.
- 건설 시 탑뷰, 카메라 이동 잠금, 종료 시 진입 전 시점 복구를 유지했다.
- 실제 하단 목록/Safe Area 크기로 농장 표시 영역을 계산한다.
- 처음 축소한 화면보다 약간 뒤로 물렸다. 검수 1920×1080에서 직교 크기 15.6370668.
- 시설 아래 조작 UI의 글자/백판을 제거했다. '배치할 수 있어요' 상태 문구는 표시하지 않는다.
- 회전·배치·취소·회수 4종 아이콘을 생성해 실제 Image/Sprite에 연결했다.
- 버튼 36×38, 이미지 30×30, 버튼 간격 4, 전체 조작 영역 164×42.
- 선택 모델의 화면 하단을 따라가며 드래그 중에는 버튼이 포인터를 가로채지 않는다.
- 최종 요청으로 바닥 포장/진입로를 위치 계산에서 제외하고 모델 아래 여백을 5→2로 좁혔다.
  먹이 창고 검수 화면에서 버튼이 이전보다 약 25화면픽셀 올라갔다.
  정원·건물의 입체 부품은 범위 계산에 유지했다.
- 가장자리 드래그 시 시설 크기와 회전을 반영해 목장 안으로 제한한다.
- 씬과 UI 프리팹의 건설 목록/조작 영역만 재구성했다. 변경 전 사본은 변경전 폴더에 보관했다.

검증 완료
- 주요 동작 23개, 목록 드래그 7개 확인 항목 통과.
  아이콘 4개 연결과 콜백, 회전, 확정, 취소, 회수, 겹침 차단,
  드래그 추적/통과, 목록 드래그 후 클릭, 카메라 고정/정확한 복귀 및 배치 보존.
- 최종 버튼 위치 변경 후 21종×4회전×3위치 = 252가지 겹침 재검사.
  모델 범위와 조작 영역의 최소 간격 3 화면픽셀(1920×1080), 겹침 0건.
- Unity 실제 Game 화면을 캡처해 01_건설화면.png로 확인했다.
- C# 변경 파일 git diff --check 통과 (LF/CRLF 안내만 존재).
- 프로젝트 스크립트 컴파일 오류 없음. Unity AI의 기존 NoSubscription 오류만 콘솔에 존재.
- 자동 검증은 실제 런타임 컴포넌트, UI 이벤트 및 배치 포인터 메서드 호출로 수행했다.
  모바일 실기 입력과 WebGL 빌드 검증은 수행하지 않았다.
- 임시 미리보기/검증 배치는 취소했고 원래 배치를 보존했다. Play를 종료해 편집 씬으로 복귀했다.
