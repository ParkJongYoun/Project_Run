목장 UI와 전체 무음 수정

요청: 전체 플레이 사운드 제거, 로비 설정 비활성, 몬스터 목록 정렬,
흙길 미화, 출전 팝업 전체 딤드, 미노타우르스 얼굴·어깨 초상 공통 적용.

적용
- Unity AudioManager의 Disable Audio 활성화.
- Mgr_Sound는 발소리·바람·알림 AudioSource를 생성하거나 재생하지 않음.
- Mgr_Game은 최초 부팅과 씬 전환 때 AudioListener.volume=0 적용.
- 로비 및 경기장 톱니바퀴는 표시를 유지하고 설정창을 열지 않음.
- 몬스터 목록: 카드 166×170, 간격 10, 상하 여백 5. 실제 이미지 테두리도 같은 영역에 맞춤.
- 이름 15~17pt 자동 맞춤, 레벨 16pt, 각 한 줄. 하단 프레임과 글자 사이 여백 확보.
- 출전 팝업은 전체 패널 아래로 이동하고 검은 딤드 alpha=0.82 적용.
  내용만 기존 Safe Area와 0.94 배율을 따름.
- 미노타우르스의 기존 얼굴 특징을 유지한 어깨 초상 제작.
  Minorous_face.png의 GUID를 유지하여 몬스터/훈련/출전 공통 참조 교체.
- PathSoftAlbedo.png 제작. 실제 목장 길과 배치 미리보기 및 건설 흙길 아이콘 연결.
  길 반복 배율 0.18, 경계 폭 0.13으로 잔디와 부드럽게 연결.
- 기존 미노 얼굴은 이전원본/미노타우르스_기존얼굴.png에 보존.
  기존 흙길 텍스처와 사운드 원본 에셋도 보존.

실행 검증
- Unity 6000.3.23f1, Game View 1920×1080.
- 타이틀 GAME START → Scene_LobbyTest → 출전 확정 → Scene_OvalToon 실제 진입 확인.
- 타이틀/로비/진행 중 경기 AudioListener.volume=0.
- 진행 중 경기 AudioSource=0개.
- PlayFoot(1), PlayAccent(true), SetWind(1) 호출 후에도 AudioSource=0개.
- 훈련 VideoPlayer와 경기 VideoPlayer 2개 모두 audioOutputMode=None.
- 로비와 경기장 설정 버튼 호출 후 설정창 미표시.
- 몬스터/훈련/출전 화면에서 새 초상 참조와 실제 표시 확인.
- 출전 팝업 딤드 좌표 (0,0)~(1920,1080), alpha=0.82 확인.
- 목록 3장 전체와 이름/레벨, 건설 화면 흙길을 캡처하여 시각 검수.
- 코드 컴파일 성공. 웹 빌드 재생성 및 브라우저 플레이는 이번 작업에서 수행하지 않음.

진단 구분
- 콘솔의 generators.ai.unity.com NoSubscription 오류는 최초 검사부터 있던 Unity AI 서비스 오류.
- MCP manage_camera 캡처 도구가 ScreenshotUtility.cs:197에서 PlayerLoop 재귀 오류를 냈고
  카메라만 캡처했음. 이후 Unity ScreenCapture.CaptureScreenshot으로 UI 포함 캡처에 성공.
- 프로젝트 게임 코드의 컴파일 오류와 위 도구/서비스 오류를 구분함.
