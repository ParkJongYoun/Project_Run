# 경기 6종 스킬 이펙트 적용 기록

작업일: 2026-10-21  
대상: `Scene_OvalToon`의 고정 출전 6종  
상태: Unity 에디터 적용 및 실제 경기 검증 완료. WebGL 재빌드와 모바일 실기기 성능 측정은 수행하지 않음.

같은 날 후속 요청으로 필살기 시점 분산 및 노말·레어 실제 성능을 추가했다. 현재 경기 규칙은 [스킬 분산·추월 AI 조정 기록](../경기스킬분산과_추월AI_20261021/조정내용과_검증기록.md)을 따른다. 아래의 노말·레어 UI 전용 설명은 최초 이펙트 적용 시점의 기록이다.

## 적용한 조합

| 주자 | 장판·발동 연출 | 스프린트 연출 |
|---|---|---|
| 포링 | 청록 물 장판, 물보라, 원형 섬광 | 청록·흰색 속도선 |
| 미노타우르스 | 황금색 장판, 충격 확산, 섬광 | 황금색 속도선, 흙먼지 |
| 페코페코 | 민트색 바람 장판, 바람 반구 | 대시와 민트색 속도선 |
| 루나틱 | 분홍색 소형 장판, 원형 섬광 | 짧은 대시와 분홍 속도선 |
| 바포메트 주니어 | 보라색 어둠 장판, 낮은 연무 | 보라색 속도선 |
| 알파카 | 백금색 장판, 나선형 버프와 별 | 백금색 속도선, 작은 바람먼지 |

각 주자의 실제 유니크 스킬 활성 구간에 표시한다. 노말·레어는 기존의 스킬 띠만 표시한다. 주자 ID를 기준으로 연결하므로 출발 레일을 섞어도 종별 이펙트가 바뀌지 않는다.

선택 주자의 영상 스킬은 영상 진입·재생·복귀 페이드가 모두 끝난 뒤 새 장판·섬광·속도선을 시작한다. 기존 카메라 진입용 파티클도 새 이펙트를 사용하는 동안 숨긴다. 영상 건너뛰기는 복귀 페이드 이후 시작하며, 영상이 없는 다른 주자는 유니크 발동 시 바로 표시한다. 영상 자체의 카메라 전환과 경기 판정은 기존 동작을 유지한다.

## 바로 끄거나 다시 켜기

- 전체 끄기: Unity 메뉴 `Tools > Project Run > Race skill effects > Disable added effects`
- 전체 켜기: 같은 메뉴의 `Enable added effects`
- 종별 끄기·크기 조절: 같은 메뉴의 `Select effect settings`에서 `Runners`를 펼쳐 해당 종의 `Enabled`, `Scale`, `Ground Height`를 조절
- 설정 파일: `Assets/Resources/RaceSkillEffects/Data_RaceSkillEffects.asset`

전체 또는 종별 `Enabled`를 끄면 해당 주자의 새 이펙트를 숨기고 기존 오라·스킬 파티클을 다시 사용한다. 편집 모드에서 설정하면 이후 실행·빌드에도 유지된다. 플레이 모드에서의 변경은 현재 화면 비교용으로 사용할 수 있다.

코드 연결까지 제거할 때는 `Sys_DemoRace.Start()`에 추가한 `Sys_RaceSkillEffects` 연결 부분만 우선 제거하면 기존 표현으로 복귀한다. 새 프리팹·재질은 독립 폴더에 있으며, 원래 몬스터·스킬 프리팹과 Project OT 원본은 변경하지 않았다.

## 코드와 에셋 범위

- 런타임 제어: `Assets/Scripts/Game/Race/Presentation/Sys_RaceSkillEffects.cs`
- 설정 형식: 같은 폴더의 `Data_RaceSkillEffects.cs`
- 독립 프리팹 6개: `Assets/Resources/RaceSkillEffects/Prefabs`
- 복사한 이펙트 원본·전용 재질·셰이더: `Assets/ArtBundles/Race/SkillEffects`
- 프리팹 조합 도구: `Assets/Scripts/Editor/Racecourse/RaceSkillEffectsBuilder.cs`
- 검증 도구: 같은 폴더의 `RaceSkillEffectsValidation.cs`
- 복사·셰이더 변환 도구: 저장소 루트의 `Tools/RaceSkillEffects/import_effects.py`
- 최소 연결 수정: `Sys_DemoRace`, `Sys_DemoSkillEffects`, `RaceRunnerView`, `Sys_RaceCinemachine`

Project OT의 Vefects 및 Lana Studio 에셋에서 선택한 프리팹과 종속 리소스 124개를 새 GUID로 복사했다. 경로·GUID 대응은 `에셋_출처와복사기록.json`에 기록했다. Vefects의 Built-in 셰이더 15개는 전용 URP 셰이더로 옮기고 원래 텍스처·그라디언트·파티클 스트림을 유지했다. 카메라의 공용 깊이·불투명 텍스처 옵션은 바꾸지 않았다.

경기 시계로 파티클을 진행하며 고정 파티클 시드를 사용한다. 경기 계산과 전역 난수는 수정하지 않는다. 일시정지·영상 홀드에서는 파티클 시간도 멈추고, 스킬 종료·결과 건너뛰기·재경기·씬 종료 때 정리한다. 새 오디오 소스와 파티클 조명은 사용하지 않는다.

## 수행한 검증

- 플레이어블 포링·미노타우르스·페코페코를 각각 선택한 실제 경기에서 6종 모두 한 번씩 새 이펙트 시작
- 세 선택 주자 모두 영상 및 복귀 페이드 중 새 이펙트 숨김, 복귀 이후 시작
- 컷씬 직전의 기존 파티클 숨김, 영상 건너뛰기 후 복귀 페이드가 끝나야 새 효과 한 번 시작, 건너뛰기 후에도 완주 기록·순위 일치
- 3배속 경기 진행, 일시정지 시 파티클 시계 정지
- 전체 끄기 시 새 효과 숨김 및 기존 효과 복구, 종별 끄기
- 결과 건너뛰기 시 모두 정리, 재경기와 레일 재배치 후 상태 초기화
- 동일 입력의 별도 경기 시뮬레이션과 최종 순위·완주 시간·스킬 발동 횟수 완전 일치
- 복사·변환한 15개 셰이더 컴파일 오류 없음
- 활성 파티클 렌더러의 재질 누락·미지원 셰이더 없음, 프리팹의 누락 스크립트·오디오 소스 없음
- 실제 경기 내 6종을 별도 확인 카메라로 촬영하여 색상·장판·속도선 확인

자동 검증 로그는 `실제경기_검증.txt`, 영상 건너뛰기 추가 확인은 `컷씬건너뛰기_검증.txt`에 구분한다. `선택0_주자0.png`부터 `선택0_주자5.png`는 같은 경기의 6종 확인용 구도이며, `선택1_주자1.png`와 `선택2_주자2.png`는 각각 선택 주자의 컷씬 복귀 후 화면이다. `실제게임화면_컷씬복귀후.png`는 HUD를 포함한 게임 화면 캡처다.

검증 전 로컬 저장은 이 폴더의 `검증전_로컬저장.json`에 보관하고 검증 종료 후 복원했다. 기존 Unity AI 도구의 구독 관련 콘솔 오류는 이번 경기 이펙트 오류와 구분했다. 웹 빌드 크기·모바일 FPS 및 사용자 외형 승인은 아직 검증한 것으로 간주하지 않는다.
