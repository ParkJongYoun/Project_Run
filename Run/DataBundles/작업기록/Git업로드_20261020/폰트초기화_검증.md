# 폰트 자동 생성의 설정 누락 처리

- 원격 UI 병합 뒤 `FontSDFBuilder` 자동 실행에서 TMP 설정이 없어 `TMP_FontAsset.CreateFontAsset`가 NullReferenceException을 냈다.
- TMP 설정이 없으면 자동 생성을 생략하고, 수동 메뉴 실행 시에는 필요한 리소스를 알리는 경고를 남기도록 보완했다. 기존 uGUI 폰트·텍스트·화면은 변경하지 않았다.
- 2026-10-20 08:41 KST: Unity 재컴파일 완료. `TMP_Settings.instance == null`인 실제 프로젝트에서 `Build(false)`를 다시 호출했고 예외 없이 반환했다.
- TMP 리소스를 새로 생성하거나 패키지를 추가하지 않았다.
