# 전송 중 추가된 원격 카메라 변경

- LFS 483개(약1.65GB) 전송 완료 뒤 일반 푸시가 원격 선행으로 거절됐다. 강제 푸시하지 않고 `c10478061`을 가져와 일반 병합했다.
- 변경은 `Scene_OvalToon`의 비어 있던 Hud 오버라이드 제거와 `cinemachine_01`의 일반 주인공 측면·정면 카메라 위치 및 오프셋이다. 스킬 영상 코드와 전용 카메라 생성 코드는 변경되지 않았다.
- Unity에서 병합된 실제 경기 씬을 PreviewScene으로 열어 Race 1개, CinemachineCamera 18개, Missing Script 0, 컴파일 중 아님을 확인한 뒤 닫았다. 병합 충돌 없음.
- UI 병합의 스킬3종52항목, 트랙 변경의 추가 페코23항목·로비16항목 실플레이 기록과 구분한다. 이 마지막 일반 카메라 조정에 대해 전체 경기를 다시 플레이하거나 WebGL을 다시 빌드하지 않았다.
