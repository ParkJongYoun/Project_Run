반영 내용
- 건설 목록에서 시설을 선택하면 현재 카메라 화면 중앙의 바닥 위치에 그리드 단위로 미리보기를 생성한다. 첫 빈칸을 찾아 자동 이동하던 처리를 제거했다.
- 시설 겹침·그리드 밖은 빨간색, 배치 가능 구역은 초록색 반투명 바닥으로 표시한다. 알파는 0.42이며 불가능한 위치에서는 배치 버튼과 실제 확정을 모두 차단한다.
- 좌클릭 드래그·한 손가락 스와이프 중 카메라가 이동하면 미리보기도 카메라 중앙을 따라 그리드에 맞춰 이동한다. 카메라 LateUpdate의 스프링 보간·관성·경계 복귀가 끝난 좌표를 사용한다.
- 설치된 시설 클릭은 일반 로비에서 카메라 포커싱만 수행한다. 건설 모드에서는 원본 위치에 이동 미리보기를 띄우고 카메라를 포커싱한다. 자동 포커싱 동안 시설은 움직이지 않으며 이후 직접 화면을 이동하면 중앙 기준 배치를 시작한다.
- 포커싱은 기존 스와이프와 같은 SmoothDamp(정지 시 0.16초)를 사용한다. 배치·포커싱 중에는 가장자리 시설까지 중앙에 도달하도록 바닥 중심 이동 범위를 사용한다.
- UI에서 시작한 드래그는 카메라·미리보기 입력으로 취급하지 않는다. 드래그 후 멈춰 잡고 있으면 이전 관성 속도가 줄어든다.
- 회전은 중앙 기준점을 유지한다. 취소는 기존 시설을 복구하며, 배치·회수는 기존 버튼을 사용한다.
- 새 조작법을 건설 안내와 수첩에 반영했다. 기존 씬을 다시 생성하지 않고 런타임 안내도 갱신한다.
- 에디터 재컴파일 시 null 미리보기가 빈 시설 데이터로 복원되던 오류를 막고, 설치된 시설 조회 사전을 OnEnable에서 재연결한다.
- 반투명 발자국 재질과 씬 생성 도구의 동일 재질 설정을 함께 갱신했다.
