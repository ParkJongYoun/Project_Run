# 경기 스킬 분산·추월 AI 조정

작업일: 2026-10-21

## 적용 기준

노말은 주자당 2회, 레어는 주자마다 경기 시작 때 1~2회를 추첨한다. 같은 주자의 노말·레어 순서와 전체 주자의 발동 순서를 섞고 예정 시간을 조금씩 달리한다. 실제 발동은 전체 스킬 사이 최소 1.6 경기 초, 필살기끼리는 최소 5 경기 초를 두며 같은 주자의 노말·레어 사이에는 최소 4초를 둔다. 필살기 직전에는 작은 스킬을 잠깐 미뤄 알림이 한꺼번에 몰리는 것을 방지한다.

이 간격은 경기 시계 기준이다. 2배속에서는 화면상 전체 최소 간격이 약 0.8초가 된다. 추첨 결과는 경기 입력의 시드로 고정되며 영상·일시정지·배속·건너뛰기가 추첨을 다시 하지 않는다.

| 주자 | 기본 필살기 시점 | 특성 |
|---|---:|---|
| 루나틱 | 14% | 초반 도약으로 선점 |
| 알파카 | 27% | 초반 안정적인 보폭과 흐름 확보 |
| 미노타우르스 | 40% | 중반 대열 돌파 |
| 바포메트 주니어 | 52% | 중반 압박과 추월 |
| 포링 | 65% | 후반 반격 |
| 페코페코 | 76% | 바깥으로 빠지는 긴 후반 스퍼트 |

각 기준에는 ±1.2%의 경기별 변화가 있다. 주변 주자 상황과 전체 발동 간격에 따라 조금 늦춰질 수 있으나, 선두라는 이유로 모든 종을 74%까지 기다리게 하던 조건은 제거했다. 선택 주자에게 60% 기준·동일한 가속량을 덮어쓰던 처리도 제거하여 선택 여부와 관계없이 종별 특성을 유지한다.

선택 주자의 영상은 해당 필살기 시점에 한 번 재생한다. 미노타우르스 선택 시 영상도 중반에 나온다. 장판과 스프린트 이펙트는 이전 요청대로 영상 및 복귀 페이드가 끝난 뒤 표시된다.

## 실제 성능과 진로

- 노말: 기본 속도를 기준으로 최대 1.2% 추가 가속, 2초. 진입·종료에 짧은 완화를 적용한다.
- 레어: 최대 2.5% 추가 가속, 3.2초. 포링·미노타우르스·알파카는 중앙 공간, 페코페코·루나틱·바포메트 주니어는 바깥 공간을 찾는다.
- 주변 주자: 레어 사용 주자가 뒤쪽 14m 안에 있으면 그 진로를 조금 비켜주는 방향을 검토한다. 앞뒤 간격과 차선 이동 경로가 안전할 때만 이동하며 위치를 순간 변경하지 않는다.
- 노말·레어 가속이 겹치더라도 합계는 3.5%로 제한한다. 현재 자기 발동 간격에서는 보통 겹치지 않는다.
- 페코페코 필살기: 가속 계수를 17%에서 34%로, 지속시간을 7초에서 13.5초로 늘린다. 선택 페코페코에도 같은 종별 값을 사용한다. 가속 반응은 초당 4.2m/s, 후반 기본 가속 계수는 8%로 조정한다.
- 페코페코는 필살기 기준보다 진행률 4.5% 앞서 바깥 진로를 탐색한다. 바깥 선호를 유지하면서 실제 우회 거리와 충돌 제한을 적용해 추월한다. 이는 카메라용 순간 이동이 아니라 경기 계산상의 주행이다.
- 인코스: 주행 허용 안쪽 경계를 기존 -7.75m에서 -6.25m로 1.5m 바깥으로 이동한다. 출발 주행선은 기존 -7~7m에서 -6~7.5m로 조정하며 여섯 종의 출발 순서 무작위 배치는 유지한다.

## 검증 결과

미훈련 108경기와 훈련 완료 108경기, 총 216경기를 고정 시드로 검사했다.

| 확인 항목 | 결과 |
|---|---|
| 6종 노말 2회·레어 1~2회·유니크 1회 | 전 경기 통과 |
| 전체 스킬 최소 간격 | 약 1.617 경기 초 |
| 필살기 최소 간격 | 약 5.017 경기 초 |
| 노말·레어 가속 발생과 상한 | 통과 |
| 실제 주행선 범위 | -6.249~7.744m |
| 배속에 해당하는 묶음 스텝과 일반 스텝의 완주 시간·순위·횟수 | 일치 |
| 레어 진로 양보 | 직선의 동일 상황에서 레어 ON일 때만 앞 주자가 1m 이상 옆으로 이동 |
| 페코페코 외곽 스퍼트 | 활성 구간 샘플의 약 86~88%가 바깥쪽 +3m 이상 |
| 페코페코 외곽 추월 | 미훈련 표본 342회, 훈련 표본 324회 |

유니크 실제 발동 구간은 루나틱 13.6~17.7%, 알파카 25.8~28.2%, 미노타우르스 38.8~40.9%, 바포메트 주니어 50.8~53.2%, 포링 63.9~66.2%, 페코페코 74.8~79.2%였다.

기존 선택 주자의 후반 역전 보정 추첨 확률 82%는 유지했다. 이번 각 36경기 표본의 선택 주자 승리는 미훈련 포링 24·미노타우르스 21·페코페코 35회, 훈련 완료 시 각각 26·25·35회였다. 추첨 확률과 실제 승률은 서로 다른 수치다. 페코페코는 이번 요청에 따라 강하게 조정된 상태이며, 이 표본을 일반 서비스의 균형 검증으로 간주하지 않는다.

계산 검증 파일은 `경기계산_반복검증.json`, `훈련후_반복검증.json`이다. 실제 선택 3종의 영상·장판·스프린트·끄기·일시정지·결과 건너뛰기·재경기도 통과했으며 `실제경기_검증.txt`에 별도로 기록했다. 선택 페코페코가 컷씬 복귀 후 바깥 차선에서 스퍼트하는 화면은 `실제게임화면_페코페코_후반외곽.png`에 보관했다. 실제 화면 캡처와 계산 검증을 구분한다. 검증 종료 후 로컬 저장을 원본과 동일하게 복원하고, 변경사항 없는 `Scene_Title` 편집 모드로 돌아왔다. WebGL 재빌드 및 모바일 FPS 측정은 이번에 수행하지 않았다.

## 변경 위치와 조절

- 편집 원본: `DataBundles/테이블/경기스킬_6종.xlsx`
- 런타임 테이블: `Assets/Resources/Tables/Table_RaceSkills.json`
- 발동 횟수·작은 가속·레어 진로·종별 필살기 수치는 위 테이블에서 관리한다. 편집 원본과 JSON을 일치시킨다.
- 추첨·발동 간격: `Data_RaceSkillSchedule`, `Data_RaceSimulation`
- 종별 입력과 페코페코 성향: `Sys_DemoRace`
- 추월·양보·안쪽 경계: `Data_RaceLaneContest`
- 출발선 재배치: `Sys_Race`

기존 이펙트 ON/OFF 메뉴는 그대로 사용할 수 있다. 이 메뉴는 화면 이펙트만 끄며, 이번에 추가한 실제 스킬 성능을 끄는 메뉴가 아니다. 이전 스킬표는 이 폴더의 `변경전_경기스킬_6종.xlsx`에 보관했다.
