# 카툰 경기 출전자 구성

2026-10-20 최신 경기 구성: 정식 레이스는 `Scene_OvalToon`만 사용한다. 플레이어블은 포링·미노타우르스·페코페코이며 세 종을 고정 출전시키고 여우·알파카·스모키·루나틱·세비지·말·바포메트 주니어·불꽃새 중 중복 없이 무작위 세 종을 추가해 총 여섯 마리로 구성한다. 카툰 테스트 씬 `Scene_CartoonTest`의 전시 부모 배율과 캐릭터 배율을 곱한 현재 비율을 경기 전용 프리팹의 `obj_visual`에 반영한다. `Tools > Project Run > Cartoon monsters > Sync race lineup from showcase`로 이후 비율을 다시 반영한다. 로비의 플레이어블·훈련·출전 대상은 위 세 종으로 통일하며, 모드 선택과 웹 빌드에서 2D 경기를 제외한다. 기존 2D 씬·원본 에셋은 보존한다. 페코페코는 전용 만화·영상 제작 전까지 경기 내 가속 효과를 사용하며 필살기 판정과 두 번의 발동은 유지한다. 이 기준은 이전의 에드가 플레이어블·2D 병행·고정 카툰 여섯 종 구성보다 우선한다.

- 경기 전용 프리팹: Assets/Resources/Prefabs/Race/CartoonRaceLineup
- 출전자 데이터: Assets/Resources/Tables/Data_CartoonRaceRoster.asset
- 플레이어블 테이블: Assets/Resources/Tables/Table_Demo.json
- 사용자 요청으로 추가 Play 테스트는 중단함. 웹 빌드 재생성은 수행하지 않음.
