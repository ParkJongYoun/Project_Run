Unity 구현 방침
- 신규 Sys_RaceSkillVideo가 여우 RunnerId=2의 Skill 이벤트를 구독한다. 현재 여우 발동 시점은 경기 시간 40초.
- VideoPlayer를 미리 준비하고, 실제 첫 프레임 도착 후 0.4초 페이드인한다.
- 경기 계산과 연출을 분리한다. 모든 주자에게 동일한 presentation hold를 적용하고 결과 계산 규칙은 변경하지 않는다.
- 종료 0.85초 전 모든 주자의 진행을 함께 재개하며 영상과 실제 여우의 달리기를 겹친다. 실제 달리기 애니메이션의 시계를 초기화하지 않는다.
- 영상에 가려진 동안 여우 전방 사선 구도로 카메라를 맞춘다. 복귀 후 잠깐 해당 구도를 유지하고 일반 중계 구도로 보간한다.
- 메뉴 일시정지는 영상 시계와 페이드도 함께 멈춘다. 메뉴는 Popup 400, 영상은 Cutscene 300이다.
- 연출 생략은 0.25초 페이드. 경기 건너뛰기 중에는 영상이 발동하지 않는다. 재시작·비활성화·오류 시 정지 소유권을 해제한다.
- 첫 프레임/재생 지연 시 무한 정지가 남지 않도록 기존 실시간 연출로 복귀한다.
- 정사각 영상은 비율을 보존해 세로 화면 중앙에 표시하며 Safe Area와 기존 판타지 폰트·이미지 버튼을 사용한다.
- 영상 내 자동 생성 오디오는 게임에서 음소거한다. 기존 게임 사운드와 중복되는 것을 피한다.
